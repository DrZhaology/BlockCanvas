## 二、这一轮修掉的真 BUG（按严重程度）

1. **画布滚动彻底错乱（滑块停在中间、越滚越短）**
   视口层的 `--bc-fl-top` 用了「当前滚动位置」下的坐标，滚一次就把滚掉的量烘进去，
   视口层被推到页面底部，把 `scrollHeight` 从 2464 一路顶到 6000+。
   修法：`(vp.top - padTop - scrollTop) / zoom`，得到滚动不变量。

2. **fixed 的包含块是整张画布**（连着三轮没修对的根子）
   画布里加了一层 `.canvas-fixed-layer`，矩形 == 红框，由它做包含块。
   于是 `bottom: 0` = 贴视口底（652），不是画布底（2758）；左下/右下角不再越界。

3. **Alt 显示四条偏移**
   盒模型浮层以前把 `top/right/bottom/left` 四个数字全标出来。现在按「场景里真的写了值」过滤。
   同时橙色墙提示也从四面收成两面（面板里两条，画布上就两条）。

4. **竖屏下半屏空白**
   宽屏 grid 行模板是「画布 + 底部面板」两行，窄屏下面板变抽屉不占格但行模板还在 →
   画布只拿 383px。现在 `grid-template-rows: minmax(0,1fr)`。

5. **竖屏抽屉面板"崩"**
   原因是工程用「元素面板放底部」布局（横向七列平铺），塞进 354px 抽屉里挤成三条、
   分类标题拉成空白竖条；且抽屉 `top:0` 没有定位上下文，飘到窗口顶上被工具栏盖住 227px。
   现在：抽屉里换回竖排 + `.workspace{position:relative}`。

6. **进退场动画"消失"**
   不是被删了，是 React 重写画布节点的 `style`/`className` 把 CSS 动画抹掉了
   （computed `animationName` 恒为 `none`）。进场改用 Web Animations API，
   退场用按原位钉住的影子克隆。

7. **滚动条盖在右侧面板上**
   滑块层 z-index 9990（比模态还高）→ 压到 45，内缩 2px → 6px。

## 三、这一轮的行为变更

- **临时卡片只在"这条属性不在下方列表"时出现**（以前开关一关就任何属性都出卡片）。
- **临时卡片没有 ×**，跟着选中元素存活。
- **不生效卡片**只保留琥珀底色，去掉虚线左边框 / 灰底 / 字变浅 / 内容降透明。
- **竖屏没有多标签页管理**：切到窄屏只保留当前标签，"+"和每个标签的 × 都不显示。
  干净的标签直接关；**有未保存修改的保留**（不静默丢用户的活）。
- **顶部菜单支持键盘**：←/→ 横移、↓/Enter/空格 打开、Esc 收起，弹出后按钮保持按下态。
