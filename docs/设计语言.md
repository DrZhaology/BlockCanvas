# BlockCanvas 积木画布 · 设计语言与 UI 规范 (Design System)

> 版本：v1.0.0  
> 目标：建立一致、极简、现代的 Windows 11 Fluent 桌面设计语言。  
> 原则：**克制、统一、直观、容错、零基础友好**。任何页面、弹窗、控件必须严格遵循本规范。

---

## 一、核心设计原则

1. **统一性（Consistency）**：同一种操作在整个软件中必须拥有完全相同的视觉形态和交互反馈，绝不允许出现五花八门的按钮与边框。
2. **防误触与双重防护（Safety First）**：删除工程等高危操作必须实施双重确认，并要求输入项目名称确认，绝不给用户留下后悔遗憾。
3. **呼吸感与防拥挤（Clean & Adaptive）**：所有按钮文本一律 `white-space: nowrap` 且 `flex-shrink: 0`，严禁文字被压碎、折行或超出边框；窄屏下通过自适应换行或折叠展示。
4. **状态共位（Shared Indicator Slot）**：标签页的“未保存小圆点 `•`”与“关闭按钮 `×`”共享同一个右侧槽位（平时显示小圆点，hover 时平滑变为关闭按钮，与 VS Code / Chrome 业界标准完全一致）。

---

## 二、色彩体系 (CSS Variables)

所有界面颜色必须严格走 `:root` 语义化 CSS 变量，确保浅色与深色模式（Dark Mode 插件）100% 完美适配：

| 变量名 | 浅色基准 | 深色基准 | 作用 |
|---|---|---|---|
| `--bg` | `#f3f3f3` | `#1b1c1f` | 软件底层背景色 |
| `--bg-panel` | `#ffffff` | `#242528` | 卡片、面板、浮层主背景 |
| `--panel-tint` | `#f7f9fc` | `#222429` | 次级面板底色、设置侧栏底色 |
| `--panel-soft` | `#fbfcfd` | `#222328` | 输入框、列表项浅色底 |
| `--border` | `#e5e5e5` | `#3a3c41` | 标准边框分割线 |
| `--text` | `#1f1f1f` | `#e8e8e8` | 正文主文本 |
| `--text-muted` | `#707070` | `#9b9da3` | 次级提示说明文本 |
| `--accent` | `#1e88e5` | `#4f9cf0` | 品牌主色（交互、激活、主按钮） |
| `--accent-hover` | `#1976d2` | `#6ab0ff` | 品牌悬浮强调色 |
| `--hover` | `#f0f0f0` | `#34363b` | 中性悬浮底色 |
| `--hover-accent` | `#f0f7ff` | `#27323f` | 带主色的轻悬浮/选中底色 |
| `--danger` | `#c62828` | `#ff6b6b` | 危险警示色（删除、错误） |

## 三、标准按钮体系 (Button System)

软件内仅允许以下 4 种标准按钮样式，高度严格规范：

```
[ 小号: height 24px, padding 0 8px, font 11px, radius 4px ]
[ 标准: height 28px, padding 0 10px, font 12px, radius 4px ]
[ 大号: height 32px, padding 0 14px, font 13px, radius 6px ]
```

### 1. 主按钮 (`.btn-primary`)
- **外观**：`background: var(--accent); color: #ffffff; border: 1px solid var(--accent-hover);`
- **使用场景**：全局最核心的正向动作（如“导出 HTML”、“保存并应用”、“新建项目”）。一屏中原则上只出现 1~2 个主按钮。

### 2. 次级按钮 (`.btn-secondary` / 默认 `.btn-mini`)
- **外观**：`background: var(--bg-panel); color: var(--text); border: 1px solid var(--border);`
- **悬停**：`border-color: var(--accent); color: var(--accent); background: var(--hover-accent);`
- **使用场景**：常规操作（如“预览”、“导入”、“复制”、“另存为”）。

### 3. 幽灵/图标按钮 (`.btn-ghost` / `.tab-action-btn`)
- **外观**：`background: transparent; border: 1px solid transparent; color: var(--text-muted);`
- **悬停**：`background: var(--hover); color: var(--text); border-color: var(--border);`
- **使用场景**：工具栏次要操作、浮动小按钮。

### 4. 危险按钮 (`.btn-danger` / `.wm-del-btn`)
- **外观**：红字白底或红底白字。
- **悬停**：`background: #fee2e2; color: var(--danger); border-color: #fca5a5;`
- **使用场景**：删除元素、删除项目、清空备份等不可逆操作。

## 四、控件与输入规范

### 1. 开关控件 (`.fluent-switch`)
- **尺寸锁定**：严格为 `width: 36px; height: 20px; flex-shrink: 0;`；
- **滑块小球**：`width: 14px; height: 14px;`，选中平移 `16px`；
- **严禁拉伸**：任何父级 flex 排版下必须 `flex-shrink: 0`，保持 100% 正圆与胶囊轮廓。

### 2. 输入框 (`input[type="text"]`, `select`, `textarea`)
- **高度**：标准 `28px`，大号 `32px`，内边距 `0 8px`；
- **边框与聚焦**：默认 `1px solid var(--border)`，聚焦时 `border-color: var(--accent); outline: none; box-shadow: 0 0 0 1px var(--accent);`；
- **文字防遮挡**：一律自带 `font-family: inherit; font-size: 12px;`。

---

## 五、布局与多标签规范

### 1. 顶部项目标签栏 (ProjectTabBar)
- **极简顶置**：仅放置项目标签页与末尾的 `＋` 新建按钮；删除一切冗余的保存/另存为操作按钮；
- **未保存与关闭共位机制**：
  - 当标签 `isDirty` 时，右侧展示直径 `6px` 的主色小圆点 `•`；
  - 当鼠标 hover 到该标签时，小圆点平滑切换为关闭按钮 `×`；
  - 移出鼠标恢复小圆点。

### 2. 气泡与提示延迟 (Tooltips & Popovers)
- 元素 hover 说明卡与小问号 `?` 统一为 **1000ms 悬停防抖延迟 + 平滑淡入**，光标轻微扫过绝不弹窗打扰；
- 离开目标后给予 250ms 缓冲时间允许光标滑入气泡内部查看。

---

## 六、危险操作双重保护规范 (Destructive Confirmations)

- **第一级防护**：标准模态提示（说明删除对象名称与所有关联备份影响）；
- **第二级防护**：必须在输入框内**原样完整输入项目名称**，校验一致后“确认永久删除”按钮方可解锁点击。
