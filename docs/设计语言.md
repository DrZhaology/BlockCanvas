# BlockCanvas 积木画布 · 设计语言与 UI 规范 (Design System)

> 版本：v1.0.0  
> 目标：建立一致、极简、现代的 Windows 11 Fluent 桌面设计语言。  
> 原则：**克制、统一、直观、容错、零基础友好**。任何页面、弹窗、控件必须严格遵循本规范。

---

## 一、核心设计原则

1. **统一性（Consistency）**：同一种操作在整个软件中必须拥有完全相同的视觉形态和交互反馈，绝不允许出现五花八门的按钮与边框。
2. **防误触与双重防护（Safety First）**：删除工程等高危操作必须实施双重确认，并要求输入项目名称确认，绝不给用户留下后悔遗憾。
3. **呼吸感与防拥挤（Clean & Adaptive）**：所有按钮文本一律 `white-space: nowrap` 且 `flex-shrink: 0`，严禁文字被压碎、折行或超出边框；窄屏下通过自适应换行或折叠展示。
4. **状态共位（Shared Indicator Slot）**：标签页的“未保存小圆点 `•`”与“关闭按钮 `×`”共享同一个右侧槽位（平时显示小圆点，hover 时平滑变为关闭按钮，与 VS Code / Chrome 业界标准完全一致）。

---

## 二、色彩体系 (CSS Variables)

所有界面颜色必须严格走 `:root` 语义化 CSS 变量，确保浅色与深色模式（Dark Mode 插件）100% 完美适配：

| 变量名 | 浅色基准 | 深色基准 | 作用 |
|---|---|---|---|
| `--bg` | `#f3f3f3` | `#1b1c1f` | 软件底层背景色 |
| `--bg-panel` | `#ffffff` | `#242528` | 卡片、面板、浮层主背景 |
| `--panel-tint` | `#f7f9fc` | `#222429` | 次级面板底色、设置侧栏底色 |
| `--panel-soft` | `#fbfcfd` | `#222328` | 输入框、列表项浅色底 |
| `--border` | `#e5e5e5` | `#3a3c41` | 标准边框分割线 |
| `--text` | `#1f1f1f` | `#e8e8e8` | 正文主文本 |
| `--text-muted` | `#707070` | `#9b9da3` | 次级提示说明文本 |
| `--accent` | `#1e88e5` | `#4f9cf0` | 品牌主色（交互、激活、主按钮） |
| `--accent-hover` | `#1976d2` | `#6ab0ff` | 品牌悬浮强调色 |
| `--hover` | `#f0f0f0` | `#34363b` | 中性悬浮底色 |
| `--hover-accent` | `#f0f7ff` | `#27323f` | 带主色的轻悬浮/选中底色 |
| `--danger` | `#c62828` | `#ff6b6b` | 危险警示色（删除、错误） |

## 三、标准按钮体系 (Button System)

软件内仅允许以下 4 种标准按钮样式，高度严格规范：

```
[ 小号: height 24px, padding 0 8px, font 11px, radius 4px ]
[ 标准: height 28px, padding 0 10px, font 12px, radius 4px ]
[ 大号: height 32px, padding 0 14px, font 13px, radius 6px ]
```

### 1. 主按钮 (`.btn-primary`)
- **外观**：`background: var(--accent); color: #ffffff; border: 1px solid var(--accent-hover);`
- **使用场景**：全局最核心的正向动作（如“导出 HTML”、“保存并应用”、“新建项目”）。一屏中原则上只出现 1~2 个主按钮。

### 2. 次级按钮 (`.btn-secondary` / 默认 `.btn-mini`)
- **外观**：`background: var(--bg-panel); color: var(--text); border: 1px solid var(--border);`
- **悬停**：`border-color: var(--accent); color: var(--accent); background: var(--hover-accent);`
- **使用场景**：常规操作（如“预览”、“导入”、“复制”、“另存为”）。

### 3. 幽灵/图标按钮 (`.btn-ghost` / `.tab-action-btn`)
- **外观**：`background: transparent; border: 1px solid transparent; color: var(--text-muted);`
- **悬停**：`background: var(--hover); color: var(--text); border-color: var(--border);`
- **使用场景**：工具栏次要操作、浮动小按钮。

### 4. 危险按钮 (`.btn-danger` / `.wm-del-btn`)
- **外观**：红字白底或红底白字。
- **悬停**：`background: #fee2e2; color: var(--danger); border-color: #fca5a5;`
- **使用场景**：删除元素、删除项目、清空备份等不可逆操作。

## 四、控件与输入规范

### 1. 开关控件 (`.fluent-switch`)
- **尺寸锁定**：严格为 `width: 36px; height: 20px; flex-shrink: 0;`；
- **滑块小球**：`width: 14px; height: 14px;`，选中平移 `16px`；
- **严禁拉伸**：任何父级 flex 排版下必须 `flex-shrink: 0`，保持 100% 正圆与胶囊轮廓。

### 2. 输入框 (`input[type="text"]`, `select`, `textarea`)
- **高度**：标准 `28px`，大号 `32px`，内边距 `0 8px`；
- **边框与聚焦**：默认 `1px solid var(--border)`，聚焦时 `border-color: var(--accent); outline: none; box-shadow: 0 0 0 1px var(--accent);`；
- **文字防遮挡**：一律自带 `font-family: inherit; font-size: 12px;`。

## 五、布局与多标签规范

### 1. 顶部项目标签栏 (ProjectTabBar)
- **极简顶置**：仅放置项目标签页与末尾的 `＋` 新建按钮；删除一切冗余的保存/另存为操作按钮；
- **未保存与关闭共位机制**：
  - 当标签 `isDirty` 时，右侧展示直径 `6px` 的主色小圆点 `•`；
  - 当鼠标 hover 到该标签时，小圆点平滑切换为关闭按钮 `×`；
  - 移出鼠标恢复小圆点。

### 2. 气泡与提示延迟 (Tooltips & Popovers)
- 元素 hover 说明卡与小问号 `?` 统一为 **1000ms 悬停防抖延迟 + 平滑淡入**，光标轻微扫过绝不弹窗打扰；
- 离开目标后给予 250ms 缓冲时间允许光标滑入气泡内部查看。

## 七、设置中心与 Fluent 卡片规范 (Settings & Fluent Cards)

设置中枢必须严格对标 Windows 11 原生「系统设置」的视觉层级与微交互：

### 1. 结构布局
- **双栏响应式**：左侧 `260px` 固定导航栏（`background: var(--panel-tint)`）+ 右侧自适应内容区（最大宽 `840px` 水平居中）；
- **导航指示条（Active Indicator）**：当前选中项左侧展示 `3px` 宽、`16px` 高的圆角品牌色竖条（`var(--accent)`），平滑指示当前所在层级；
- **页面切换动画**：切换导航项时，右侧卡片容器触发 `0.18s` 平滑缓入过渡动画（`popFadeIn`），不突兀、不闪烁。

### 2. 标准卡片 (`.fluent-card`)
- **基础排版**：`padding: 14px 20px; border-radius: 8px; border: 1px solid var(--border); background: var(--bg-panel);`；
- **微交互悬浮（Card Hover）**：鼠标悬停时轻微提升对比度（`border-color: var(--accent); box-shadow: 0 2px 8px rgba(0,0,0,0.04);`）；
- **对齐规范**：左侧图标（20px）居中对齐、中间文本自动换行自适应、右侧控制控件（Switch、Select、Button）严格垂直居中（`align-self: center; flex-shrink: 0;`）；
- **分组标题 (`.fluent-group-title`)**：文字大小 `12px`，字重 `600`，间距 `16px 0 6px`，搭配大白话说明。

### 3. 数据指标宫格 (`.fluent-storage-grid`)
- 4 宫格信息卡片一律采用 `background: var(--panel-soft)` 与 `border-radius: 6px`，主数值用等宽数字字体（`Consolas / Segoe UI`）加粗展示，分类明确。

## 八、版本与变更记录规范
- 任何重大 UI 改造必须在本文档留下规范条目，并在 `docs/开发历程.md` 中按时间戳倒序归档。

- **第一级防护**：标准模态提示（说明删除对象名称与所有关联备份影响）；
- **第二级防护**：必须在输入框内**原样完整输入项目名称**，校验一致后“确认永久删除”按钮方可解锁点击。

## 九、v0.4.1 补充规范（动效 / 工具栏 / 渐变 / 图标）

### 1. 展开与收起动效（强制 0.3s）
- 任何「展开 / 收起」区域 **禁止使用条件渲染**（`{open && <div/>}`），一律使用 `components/Collapse.tsx`。
- 统一时长 **0.3s**，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`，叠加 `opacity` + `translateY(-4px → 0)`。
- 收起必须有出场动画（动画结束才卸载）；动画结束后 inner 的 `overflow` 放开为 `visible`，避免裁切下拉菜单。
- 弹层类（抽屉、下拉菜单）同样需要出场动画：用 `is-closing` 状态 + 180~240ms 后卸载。

### 2. 工具栏分组规范
- 顶部工具栏固定四段：**编辑（复制/剪切/粘贴/副本/删除）→ 视图（画布宽度/缩放/轮廓）→ 检查（类名检查/导出元素模板/取消选中）→ 输出（预览/全部项目/导出 HTML/设置）**。
- 段间用 1px `var(--border)` 竖线分隔；「检查」段起右对齐（`margin-left: auto`）。
- 按钮只允许 4 种语言：`.tb-btn-ghost` / `.tb-btn-soft` / `.tb-btn-primary`（一屏仅 1 个）/ `.tb-btn-icon`。
- 同一功能只允许一个入口：设备切换只在画布顶部设备条，工具栏不再重复。

### 3. 设备 / 断点 / 画布宽度
- 三者是**同一个状态**，统一走 `lib/device.ts`（`requestDevice()` 广播 `bc:set-device`）。
- 电脑 → 自适应窗口；平板 → 768px；手机 → 375px；自定义宽度按 `≤480 / ≤768 / 其余` 落回最近断点。
- 设备切换条必须常驻画布顶部，**未选中元素时同样可用**。

### 4. 数值输入规范
- 4 边属性（margin / padding / border-radius / border-width）**必须**用 4 个独立数值框（`TrblInput` / `Box4Input`），禁止要求用户手写 CSS 简写。
- 数值框只填数字，单位用后缀或下拉；`auto` / `%` / `calc()` 允许直写并原样透传。
- 落库写 longhand 字段，导出由 `simplifyStyle` 合并简写，保证导出代码干净。

### 5. 颜色与渐变
- 「背景颜色」统一使用 `BackgroundInput`，提供 **纯色 ↔ 渐变** 双模式。
- 渐变一律用 `lib/gradient.ts` 的结构化模型 + `serializeGradient()` 序列化，**禁止手拼字符串**；
  必须能无损解析模板里手写的 `linear-gradient(...)` / `radial-gradient(...)`。
- 预制配色统一放在 `GRADIENT_PRESETS`（按 暖色系 / 冷色系 / 自然系 / 高级感 分组）。
- 文字渐变必须走「三件套」：`background-image` + `background-clip:text` + `-webkit-text-fill-color:transparent`（键名用 `WebkitBackgroundClip` / `WebkitTextFillColor` 以保证导出为 `-webkit-` 前缀）。

### 6. 快捷助手（原布局助手）
- 命名统一为「快捷助手」，定位是「把多条 CSS 属性配合才能做出的效果打包成一句话」。
- 每个块必须提供 `?` 帮助卡（原理 + 用法），帮助按钮**不得嵌套在 `<button>` 内**。
- 代管属性必须在 `HELPER_MANAGED_KEYS` 中登记，并受「是否显示到下方 CSS 属性」开关控制；
  开关状态按选择器共用记忆（`bc-helper-in-css-<scope>`），用户显式添加过的属性不受影响。

### 7. 伪类动效
- 每个伪类必须提供 ≥4 个预制动效（`PSEUDO_PRESETS`），点击即套用。
- 套用后必须提供滑块微调（位移 / 缩放 / 旋转 / 阴影 / 过渡时长 / 圆角），拖动瞬态、松手入栈。
- `transition` 由「交互状态」区域统一管理，**不得**在「CSS 样式属性」列表里重复出现。

### 8. 图标规范
- 界面图标统一走 `components/Icon.tsx`（24×24 网格 / 1.7px 描边 / 圆头圆角 / `currentColor`），保证深浅主题自动适配。
- 左侧导航栏按产品要求保留简洁 Emoji，卡片与操作按钮一律用 SVG。
