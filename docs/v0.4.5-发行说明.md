# BlockCanvas v0.4.5 发行说明

> 阶段 5 · 界面与交互全面打磨（测试版）
> 发布日期：2026-10-25

---

## 一、这个版本在做什么

v0.4.5 是一次**以"用户验收反馈"为驱动的全面打磨**。整个版本没有引入新的功能大类，
而是把 v0.4.4 阶段 4 遗留的交互粗糙处、以及你在试用中逐条提出的问题，一条一条修到位。

一句话概括：**让"能用的功能"变成"顺手的功能"。**

本版本累计 3 个提交、约 1.6 万行改动，新增 **52 个自动化探针**（全部通过），
覆盖变量系统、Alt 交互、中键搜索、媒体、定位、更新器、项目库、加载页、快照预览等全部改动面。

---

## 二、重点更新（按影响面排序）

### 1. 定位系统（position）——本轮改动最集中、返工最多的一块

| 能力 | 说明 |
| --- | --- |
| **只锚定两边** | 界面从"上/右/下/左 四个输入框"改成**两根轴各一行**：横向「左/右」+ 一个数值、纵向「上/下」+ 一个数值。切换锚定边时另一边自动写 `auto` —— 不会再出现"四个边同时给值导致元素变形/不动" |
| **负偏移自动纠正** | 绝对 / 固定定位的 `left/right/top/bottom` 小于 0 时统一按 0 处理（relative / sticky 的负位移是合法语义，保留不动） |
| **切换定位方式先问 margin** | 元素已有非零 / 不对称外边距时，切换定位方式会先弹一条内联确认：「清掉 margin 再切换 / 保留原 margin / 取消」。这解决了长期存在的"改了定位却拖不动、位置差一截" |
| **fixed 自动适配视口** | fixed 的包含块固定为"画布 = 浏览器视口"，居中改用单边 `calc(50% - 一半)`，不再四边一起改；换任何屏幕宽度都居中 |
| **双边约束可拖动** | 两边都锚着（且没写宽/高）的元素，拖动时"两边一起平移"，尺寸严格不变 —— 以前一拖就塌（实测 849px 宽变 60px、520px 高变 0） |
| **消除闪烁 / 瞬移** | 拖动位移改用指针原始增量，不再用被"墙"夹取过的目标值；松手贴边吸附会跳过双边轴 |

### 2. 中键属性搜索（逻辑大幅简化）

在画布上对元素按**鼠标中键**，敲属性名，直接跳到右侧面板对应那一行。

新的规则（比之前简单得多）：

- 结果**只显示 3 条**，每行 = **属性中文名 + 属性英文名 + 「已添加 / 未添加」**；
- 默认选中第一条（**淡蓝色卡片底**，去掉了原来的左侧蓝色竖线）；
- **↑ ↓** 在 3 条结果里移动；
- **Enter / 左键单击** = 定位到右侧对应行；
- **Ctrl + Enter / Ctrl + 左键** = 添加并定位（未添加过的属性用这个）；
- 未添加时按 Enter 不会偷偷改样式，只提示一句。
- **原来的「属性 + 值」预测已移除**（你要求删掉，让交互更直接）。

### 3. 更新器重写（Windows）

以前更新会弹好几个窗口、有时不重启、`.update` 目录删不掉、目录名改不动。现在：

- **只弹一个窗口**：整套替换流程用隐藏窗口的 PowerShell 脚本跑，全程零可见控制台；
- **一定重启**：无论成功失败都会重新拉起程序（失败也能继续用旧版本）；
- **目录名统一**：更新后程序文件夹固定改名成 `BlockCanvas`（不再带版本号/时间戳，桌面快捷方式不会失效）；
- **`.update` 自动删除**：带重试的递归删除，修掉了 `ENOTEMPTY: directory not empty` 这个报错；
- **日志全量落盘**：`data/logs/update-YYYYMMDD.log`，更新遮罩里还能**实时滚动查看**，并有「打开日志目录」按钮；
- **打包产物也改了**：zip 里自带 `BlockCanvas/` 这一层，解压出来就是 `BlockCanvas\BlockCanvas.exe`。

### 4. 媒体（图片 / 视频 / 音频）

| 能力 | 说明 |
| --- | --- |
| **路径三种写法** | 相对路径 / 绝对路径 / URL。界面显示的是**给你看的写法**，程序同时记录一份**权威绝对路径**（`srcAbs`）——所以"工程放哪都能找到图" |
| **导出自动匹配相对路径** | 导出改成**选一个文件夹**（不是选单个 html）。程序按导出位置重算每个媒体的相对路径，并把文件一起拷进 `assets/`，整个文件夹搬到哪都能用 |
| **导出进任务栏** | 导出过程是一条**任务**，工具栏「任务」里能看到进度 |
| **记住导出目录** | 每个工程会记住上次导出的文件夹，下次自动作为默认位置 |
| **播放锁死** | 一键锁死：视频**定格在第 30 帧**（看得出是视频，不是白屏）、音频保留播放条；锁死瞬间如果正在播会立刻停 |
| **自动播放锁静音** | 开了自动播放，静音开关会锁死在"开"（浏览器硬性要求），不能手动关 |
| **图片比例** | 没有 src 的占位图可以自由改宽高；**有 src 的图片锁比例**，并在解码后自动校正成真实比例（不再被压成 200×120） |
| **音频可选中** | 以前音频"怎么点都选不中"，现在未选中时显示一条「♪ 音频」占位条，点一下就选中；选中后才露出真正的控制条试听 |

### 5. 项目库 / 项目中心

- 表头改成**一个圆形小问号**，点开是说明卡（点外面 / Esc 关闭，带退场动画）；
- **每个项目都标类型**，各有配色：网页项目 / 网站项目（多页，下一版）/ 外部项目 / 文件已丢失；
- **删除项目时会检测会话**：如果这个工程还开在编辑器里，会提示并给「关闭这个会话」按钮 —— 不关掉就不允许删（以前删完再按 Ctrl+S 会把文件写回来）；
- 历史快照抽屉：补上了**关闭动画**；「只读预览 / 作为草稿打开」两个按钮之间加了间距。

### 6. 启动与加载

- **加载页**：Logo + 真实进度（不是假进度条）+ 丝滑过渡；底色固定白色（不再跟随深色模式变黑）；淡入 0.42s、淡出 0.55s，只过渡透明度（不抖动）；
- **首页背景预热**：趁加载页还盖着就把首页的图片/视频背景预热好，进首页不再"先白一下再出图"；
- **启动不再强行跳转**：以前发现新版本会直接把界面切成更新中心，现在只在底部飘一条提示；
- **主界面颜色模式记忆**：首页用深色背景的话，下次启动首帧就是深色文字，不再"等一会儿才变白"。

### 7. 编辑器交互

| 能力 | 说明 |
| --- | --- |
| **Alt 手势分工** | Alt+悬停 = 显示盒模型读数；**Alt+滚轮 = 精准微调位置**（1px/格，Shift 加速 10px，且不弹盒模型）；Alt+按住拖动 = 移动；**Alt+拖动+滚轮 = 滚动画布且元素跟手**；Ctrl+滚轮 = 缩放 |
| **Alt 拖动无限画布** | 按住 Alt 往画布下方拖时，画布会**自动向下生长**，不用先手动拉长画布 |
| **变量按类型过滤** | 颜色属性只列颜色变量、尺寸属性只列尺寸变量；var 弹框永远不出窗口 |
| **全程序 z-index 标尺** | 统一的层级标准（画布覆盖层 / 面板 / 弹窗 / 提示…），弹窗统一避让工具栏与底部面板 |
| **三处板块切换动画** | 右上角页面设置、下方元素插入栏、项目信息小问号 —— 都补上了进场/退场过渡 |
| **图层定位** | 选中元素时，图层列表把它滚到**容器垂直中线**（以前贴在列表最下沿，看起来像"最后一条"） |
| **幽灵卡片** | 中键搜 `position` 回车，右侧会**临时**弹出一张定位卡，就地改，不用去快捷助手翻 |
| **页面/变量字体** | 复用元素的「字体库」弹窗（可搜索本机字体、预览、看商用许可证徽章） |
| **属性卡片横向滚动条** | 删掉卡片时不再短暂冒出左右滚动条 |
| **撤销历史** | 撤销栈随工程保存，重开项目 / 切标签都能继续 Ctrl+Z |

### 8. 性能

- **动画总督**：自动检测掉帧（p95 > 28ms 连续 3 个窗口）降级到"精简档"，恢复后再回"完整档"；尊重系统「减少动态效果」；
- **后台降载**：窗口真正最小化/切走时，停掉页面内**所有**无限循环动画（不只是我们自己的），CPU 不再空转；
- **图片**：懒加载 + 异步解码 + 4K 图自动降采样 + 素材缩略图缓存（256px）；
- **素材库**：分批渲染（60 个素材不会一次全挂 DOM）+ 视口外不排版。

### 9. 桌面集成

- **图标高清化**：任务栏 / 窗口 / 安装包统一用三色 Logo（1024×1024 源图，多尺寸 ICO）；
- **`.bcproj` 文件关联**：双击工程文件直接打开（单实例锁 + 启动参数解析），并有专属文件图标。

### 10. 其它

- **只读快照预览**：只保留右侧**一张**面板，所有信息与动作（覆盖回项目 / 另存为新项目 / 退出预览）都在里面，宽度固定不再记忆；
- **帮助文档搜索**：命中关键词用**黄色荧光笔**标出，定位改为"滚到容器中心"（以前会偏）；
- **深色模式**：把散落各处的硬编码浅色收敛成语义变量（`--surface-*` / `--line` / `--text-*`）；
- **测试窗口不抢前台**：自动化脚本启动的窗口显示在屏幕外且不激活 —— 你干别的事时不会再被打断。

## 四、本版已知问题

> 这些问题**已知、未在本版修完**，会放到下一版处理。发布说明如实列出，不藏。

1. **fixed 定位的"空气墙"**：fixed 元素在画布上的可移动范围仍受画布实际高度限制 —— 画布不够高时上下"动不了"。需要把"浏览器视口高度"与"画布渲染高度"解耦。
2. **sticky 定位**只支持基础的 top/bottom 写入，还没有"滚动到某位置就粘住"的可视化预览。
3. **更新器跨平台**：macOS / Linux 的替换脚本尚未在真机验证（本版重点修的是 Windows）。
4. **`ffmpeg Unsupported pixel format` 日志**：这条来自 Chromium 原生解码器，JS 无法屏蔽。已做到"不误判、不拉黑、不换壁纸"，但根因（换解码路径）未处理。
5. **性能专项未做完**：图片解码峰值内存、合成器层数、后台 rAF 循环审计 —— 本版只做了"隐藏时停动画"这一半。
6. **多页工程（网站项目）**：项目类型里已预留识别（`manifest.meta.pageCount > 1` 自动标为"网站项目"），功能本身未实现。

## 五、升级建议

- **从 v0.4.4 升级**：直接下载新包覆盖即可。`data/` 目录（全部工程、快照、素材、插件、配置）**不会被触碰**；
- 升级后程序文件夹会自动改名成 `BlockCanvas`，桌面快捷方式建议重新指向 `BlockCanvas\BlockCanvas.exe`；
- 如果你之前手动改过程序文件夹名，改名逻辑会保留你自起的后缀（只剥掉版本号/时间戳/平台后缀）；
- 更新失败可以在 `data/logs/update-YYYYMMDD.log` 里看到每一步的详细日志。
