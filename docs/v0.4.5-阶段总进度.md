## ⑤ v0.4.4 剩余（进行中）

### 已完成：素材打包 + 路径基准（提交见 git log）

**解决了什么**：以前元素里引用的本地图片写的是 `bc-img://file/<你电脑上的绝对路径>`，
换台机器、或把工程挪个目录，图片就全丢。现在：

- **保存**：扫一遍场景，把所有 `bc-img://file/...` 指向的文件读进来，
  按内容 sha1 命名塞进 `.bcproj` 的 `assets/`，同时把引用改写成 `bc-img://asset/<hash>.<ext>`
- **打开**：把容器里的 `assets/` 解到 `data/cache/assets/`，协议直接从那里服务
- **导出**：导出的 HTML 里 `bc-img://` 引用**内联成 data URI**，发给别人也不会是破图
- 内容哈希命名 → 同一张图被十个元素引用也只存一份；重复保存不会重复塞

探针：`probe-v045-assets.mjs` **6/6**（写真图片 → 保存 → 检查 ZIP 里有 assets/ →
重开检查引用已改写 → 用 `bc-img://asset/...` 真的把图加载出来）

### 已完成：外部工程登记（提交见 git log）

**解决了什么**：`project:list` 只扫 `data/projects/`，用户从别处导入的工程**根本不出现在项目列表里**，
下次想找只能重新"打开文件"翻目录。

- 打开一个位于 `data/projects` 之外的工程时，自动登记到 `data/external-projects.json`
- 项目列表把外部工程并进来，带 `external: true` 标记（可与内置工程区分）
- **文件被移动/删除后不会无声消失**：保留一条 `missing: true` 记录并提示"文件已不在原位置"
- 新增 IPC `project:forget-external`，可从列表里移除登记（不动磁盘文件）
- **UI**：项目中心卡片上显示「外部」徽标；文件丢失的卡片降透明 + 虚线边 + 「文件已丢失」徽标，
  只保留「移除记录」按钮（其余操作隐藏，避免点了报错）

探针：`probe-v045-external.mjs` **9/9**（含 UI：徽标存在、丢失卡片样式、点移除后卡片消失）
