## 已完成

### ① 变量系统（提交 `c986c86`）

| 你的要求 | 现在怎么样 |
| --- | --- |
| 名称自由度不够 | 允许大小写字母、数字、连字符、下划线（`Brand_2`、`space_md` 都能用），不再强制小写、不再要求字母开头 |
| 强制加 `bc` 前缀 | 新变量就是 `--<名字>`；界面和导出都按你写的显示 |
| margin / padding 用不了变量 | 四值输入（padding/margin）新增 `var` 入口，一键四边引用；手输 `var(--x)` 也原样保留，不再被拼上 `px` |
| 老工程要不要迁移 | **不需要改任何文件**：`:root` 里同时输出 `--x` 与 `--bc-x`，老工程里的 `var(--bc-x)` 打开就还能用 |

探针：`probe-v045-tokens.mjs` **8/8**

### ② 定位系统可视化（提交 `a5d37b5`）

- **fixed / absolute / sticky**：画布上用红色标签标出 top / right / bottom / left 的**真实值**（没设的显示 `auto`），并附一句该定位方式的基准说明（窗口 / 最近定位祖先）
- **relative**：画出「元素原本在文档流里占的位置」虚线幽灵框（位置 = 当前 − 偏移）
- **margin: auto**：computed 会把 auto 算成像素，改为回场景样式读，画布上直接显示 `auto`
- **sticky**：显示吸附边；**static**：不再画偏移标签
- 体验改进：**Alt 悬停**就显示盒模型浮层（以前必须按住拖动才看得到）

探针：`probe-v045-position.mjs` **5/5**

### ③ 首页（提交 `7920f5c`）

- **视频壁纸报错**：选视频时先探能不能解码，解不了直接拒绝并提示换 mp4/webm；播放中解码失败则**自动回退到预设背景并覆盖本地存储里的坏配置**——以前每次进首页都重试、每次刷同一条 ffmpeg 错误
  > 说明：`Unsupported pixel format: -1` 是 Chromium 原生解码器打的日志，JS 无法屏蔽；能做到的是"不再重复触发"
- **入场动画**：从"整块上移 7px"改成**逐项错峰上浮**（Logo → 标题 → 搜索 → 按钮 → 最近项目），0.52s ease-out，延迟 0.02→0.26s 递增
- 顺带修掉：调模糊度时右侧冒滚动条 / 整页轻微上下滑（`overflow:hidden` + 面板自己内滚）

探针：`probe-v045-home.mjs` **4/4**
