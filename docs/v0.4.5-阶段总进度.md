## ⑤ v0.4.4 剩余（进行中）

### 已完成：素材打包 + 路径基准（提交见 git log）

**解决了什么**：以前元素里引用的本地图片写的是 `bc-img://file/<你电脑上的绝对路径>`，
换台机器、或把工程挪个目录，图片就全丢。现在：

- **保存**：扫一遍场景，把所有 `bc-img://file/...` 指向的文件读进来，
  按内容 sha1 命名塞进 `.bcproj` 的 `assets/`，同时把引用改写成 `bc-img://asset/<hash>.<ext>`
- **打开**：把容器里的 `assets/` 解到 `data/cache/assets/`，协议直接从那里服务
- **导出**：导出的 HTML 里 `bc-img://` 引用**内联成 data URI**，发给别人也不会是破图
- 内容哈希命名 → 同一张图被十个元素引用也只存一份；重复保存不会重复塞

探针：`probe-v045-assets.mjs` **6/6**（写真图片 → 保存 → 检查 ZIP 里有 assets/ →
重开检查引用已改写 → 用 `bc-img://asset/...` 真的把图加载出来）

### 已完成：外部工程登记（提交见 git log）

**解决了什么**：`project:list` 只扫 `data/projects/`，用户从别处导入的工程**根本不出现在项目列表里**，
下次想找只能重新"打开文件"翻目录。

- 打开一个位于 `data/projects` 之外的工程时，自动登记到 `data/external-projects.json`
- 项目列表把外部工程并进来，带 `external: true` 标记（可与内置工程区分）
- **文件被移动/删除后不会无声消失**：保留一条 `missing: true` 记录并提示"文件已不在原位置"
- 新增 IPC `project:forget-external`，可从列表里移除登记（不动磁盘文件）
- **UI**：项目中心卡片上显示「外部」徽标；文件丢失的卡片降透明 + 虚线边 + 「文件已丢失」徽标，
  只保留「移除记录」按钮（其余操作隐藏，避免点了报错）

探针：`probe-v045-external.mjs` **9/9**（含 UI：徽标存在、丢失卡片样式、点移除后卡片消失）

### 已完成：损坏工程处理（提交见 git log）

**解决了什么**：工程打不开时只丢一句「不是有效的工程文件」，用户完全没有出路。

- **提示不再含糊**：说明失败原因（JSON 解析位置 / 容器读不出来 / 缺 scene），
  并点明常见成因（保存时断电、磁盘满、网盘同步了半截文件）
- **给出出口**：弹窗直接提供「尝试修复」，修不回来再引导去「历史快照」
- **抢救逻辑**（`salvageProject`，**只读、不改原文件**）依次尝试：
  1. 常规读取
  2. 纯 JSON（旧版工程）取 `scene` / `root`
  3. ZIP 容器逐个 `.json` 条目解析，找带 `scene` 的（能从 `scene.backup.json` 这类备份条目里捞回来）
  4. 兜底把 `manifest` 里的工程名捞出来，至少告诉用户"这是哪个工程"
- 抢救出来的场景开成**未保存的新标签**（名字带「已修复」），确认没问题再另存 —— 绝不覆盖原文件

顺带发现：**缺 manifest 的容器其实本来就能打开**（`readProject` 会退到直接读 `scene.json`），
所以探针里把这条从"应该报错"改成了"应该能打开"——程序比预期更健壮。

探针：`probe-v045-salvage.mjs` **6/6**（手写三种坏文件：非 ZIP 垃圾 / 缺 manifest / scene.json 损坏但有备份条目）

### 已完成：更新器日志（提交见 git log）

**解决了什么**：更新出问题时用户只能说"更新失败了"，我们看不到**哪一步、哪个镜像、什么错误**。

- 关键事件按天写入 `data/logs/update-YYYYMMDD.log`：应用启动（版本号）、
  拉取发行版列表、**每个镜像成功/失败与回退顺序**、下载与安装的关键节点
- 原则：日志写不进去**绝不影响更新本身**（全部 try-catch 吞掉）
- 新增 IPC `update:log-path` / `update:log-tail`（读尾部 N 行），界面可挂"查看日志"入口

探针：`probe-v045-updaterlog.mjs` **6/6**（真实拉到了 7 条发行版，日志里能读到镜像成功记录）

### 已完成：音视频元素（提交见 git log）

**先纠正一个事实**：交接文档写"现在只有 video 元素类型，缺音频"——实际查下来
`ElementType` 里**两个都没有**，元素面板也只有图片/图注/分割线。

- 类型系统：`ElementType` 新增 `video` / `audio`；新增 `MEDIA_TAGS` 单独标记

  `controls`、`loop`、`muted`、`playsinline`，可直接播放预览
- 导出：带上 `src` / `controls` / `loop` / `muted` / `playsinline`，且输出 `<video …></video>` 闭合形式

探针：`probe-v045-media.mjs` **7/7**（面板入口存在、canvas 真的渲染出 video/audio 且属性正确、图层树识别）
