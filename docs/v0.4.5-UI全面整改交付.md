## 一、这次改了什么（按你截图里能看到的顺序）

### 1. 首页：内容不再"全挤在上半屏"

**问题**：1440×900 的窗口里，Logo 到三个按钮只占了上面 40%，下面 700px 全是空的，
看起来像"页面没加载完"。

**改法**：`.empty-home` 从"顶部对齐 + 10vh 上内边距"改成**垂直居中**（`align-items:center`），
矮窗口（< 760px 高）自动退回顶部对齐，避免内容被挤出屏幕。

**实测**：上下留白各 288px，完全对称（探针第 1 项）。

---

### 2. 首页渐变：色标卡片"前面一大片空白"

**问题**（你点名的）：色标卡片里颜色输入框挤在左边一小条，右边空一大片，
位置滑块单独占一行还缩在中间。

**根因**：`11-editors.css:331` 给 `.grad-stop` 设了 `align-items:center`，
后来 `14-v04x-append.css:965` 把它改成两行（`flex-direction:column`），
但**没改对齐方式**——于是两行都按"水平居中 + 内容宽度"收缩，行宽只剩内容那么宽，
看起来就是左边一坨、右边全空。

**改法**：
- `.grad-stop { align-items: stretch }`，两行都铺满卡片宽度；
- 第二行（位置滑块）左侧对齐到颜色输入框下方（`padding-left:20px`）；
- 给色标卡片补回**真正的卡片底**：1px 边框 + 白底 + 极轻投影。
  （`19-v043-ui.css` 之前把边框设成 `transparent`，卡片和面板糊成一片，看不出是两张卡。）

**实测**：`align-items=stretch`，卡片宽 297px、行宽 279px（左右各 9px 内边距），
卡片底色 `rgb(251,252,253)`（探针第 2–4 项）。

---

### 3. 外轮廓：线"直接显示到外面"

**问题**（你点名的）：外轮廓预览框上直接画 `outline`，
而 CSS 的 `outline` 天生画在盒子**外面**——12px 粗的线直接糊出卡片、盖住上面的标题。

**改法**：预览区改成"外层留 16px 内边距 + 内层小盒子画轮廓"，
外层 `overflow:hidden` 兜底。线再粗也只在卡片里。

**实测**：`padding-top=16px`、`overflow=hidden`；给内盒加 12px 红色轮廓后，
内盒四边仍完全落在卡片内（探针第 10–11 项）。

---

### 4. 属性面板：每个属性名前面那个"子"字

**问题**：属性标题写成 `[子] 宽度 (width)`，那个小方块里的"子"看起来像乱码/错字，
而且**每一个属性都有**，一屏下来十几个。

**改法**：只在属性**真的作用于父容器**（flex / grid 这类）时显示一枚"父级"小标签，
其余属性不再堆字——分类已经由左侧色条和分组标题表达了。

**实测**：属性标题行里的裸"子/父"字形 **0 个**（探针第 9 项）。

---

### 5. 属性面板：那张"样式还没有名字"的大黄卡

**问题**：每个新建元素都会顶出一张 ~180px 高的黄色警告卡，
占掉面板 1/4 高度，写着"这 15 项样式会以行内样式导出…"，天天看就是噪音。

**改法**：压成**一行**（41px）：图标 + 一句「样式还没有名字，伪类样式导出后会失效」+「起个名字」「类名总览」两个小按钮。
完整原因放进悬停提示，需要时再看。

**实测**：高度 41px（探针第 8 项）。

---

### 6. 元素面板：底部同时冒出 7 条滚动条

**问题**：底部元素面板是 7 个分组列，每列各自 `overflow-y:auto`，
一打开就是 7 条滚动条，而且每列只能露出 5–6 个积木。

**改法**：改成**整块只保留一条滚动条**——外层 `.element-body` 统一滚动，
分组高度自动等高（最高那列决定），组内网格不再滚动。
顺带把列内滚动条压到 4px、只在悬停时显形（原本连 `scrollbar-width:thin` 都会让 Chromium
忽略自定义滚动条样式，反而更粗，已在 CSS 里写明原因防止以后又改回去）。

**实测**：`element-body overflow-y=auto`、`element-grid overflow-y=visible`（探针第 6–7 项）。

---

### 7. 图层树：文字预览压到操作按钮上

**问题**：`T p ·左侧拖入积木, 右侧调整样式, 随时导出成干净的HTML。` 这一长串
直接顶到右边 6 个操作图标底下，两边叠在一起。

**改法**：文字预览 `max-width:42%` + 省略号；操作按钮 `margin-left:auto` 固定在右侧；
图层树整体禁止横向滚动。

**实测**：`max-width=42%`、`text-overflow=ellipsis`、`overflow-x=hidden`（探针第 12–13 项）。

---

### 8. 标签栏右侧那条"技巧提示"像输入框

**问题**：它带边框、带底色、带关闭按钮，宽度 500px，和标签挤在一起，
第一眼会以为是"搜索框"或"地址栏"。

**改法**：去掉边框和底色，只留一枚淡灯泡 + 一行灰字，最宽 380px；
关闭按钮改成悬停才显形。

**实测**：`border=0px none`（探针第 5 项）。

---

### 9. 添加属性菜单：会顶出窗口底部

**问题**：菜单按 `max-height` 撑到 460px，而 JS 判断"下面放不放得下"用的是 380px，
于是经常出现"以为放得下、结果底部被窗口切掉"。

**改法**：把 CSS 限高**对齐**到 JS 的 380px（并在 CSS 里写清楚这个耦合关系），
搜索框补回可见的占位文字颜色。

**实测**：`max-height=380px`（探针第 14 项）。

---

### 10. 颜色色块：白色看不见边界

**问题**：`#ffffff` 这类颜色的色块在白底卡片上等于隐形，看起来像"被切掉了"。

**改法**：色块加 1px 内描边，任何颜色都有边界。

---

### 11. 新增：**只读快照预览**（这条是「未完成清单」里的 2.1）

**以前**：项目中心点「载入此版本」，会**直接开一个可编辑的新标签**当草稿，
原工程还是旧的——用户很容易以为"已经恢复了"，其实只是开了个副本。

**现在**：快照有两种打开方式，职责分明：

| 入口 | 行为 |
| --- | --- |
| **只读预览**（新，主按钮） | 开一个带相机图标的淡紫标签，画布/属性面板全部只读，**不动任何文件** |
| 作为草稿打开（次按钮） | 老行为：复制成可编辑草稿，适合"我想在这个版本上继续改" |

只读预览标签里：
- 顶部工具条换成三个动作：**覆盖回项目** / **另存为新项目** / **退出预览**；
- 左侧元素面板换成一张"这是历史快照"的说明卡（不放积木，避免误拖）；
- 右侧属性面板换成快照信息（项目名、时间、元素数、变量数、快照文件路径）；
- 关闭标签**不弹"要不要保存"**（本来就没得保存）；
- 全局快捷键（Ctrl+S / 导出 / 删除 / 方向键微调…）在只读标签下整体失效。

**覆盖回项目**是危险动作，做了三层保护：
1. 二次确认，文案写明"当前内容会被替换、覆盖前会自动备份"；
2. 覆盖前**先把项目当前状态存一份快照**（后悔药）；
3. 覆盖完成后，如果原工程正开着，那个标签会**自动刷新成回退后的内容**并清掉未保存点。

**实测**：只读工具条/左侧说明/右侧信息/标签配色/画布 `pointer-events:none`/关闭不提示，
6 项全部通过（探针第 15–20 项）。

### 12. 新增：**定位助手**（快捷助手里）

把"position + left/top/right/bottom + margin:auto"这套要**配合起来才生效**的属性，做成几个按钮：

- 定位方式下拉：默认流式 / 相对 / 绝对 / 固定 / 粘性；
- 选非 static 时出现 上/右/下/左 四个偏移输入；
- 三个动作：**水平居中**、**垂直居中**、**清除定位**；
- 一行提示说清"居中需要元素有明确宽/高"。

放在「快捷助手 → 定位助手」里，默认折叠，不占地方。

### 13. 修掉：独立弹窗的任务栏图标是 Electron 默认图标（你要求记进待办的 BUG）

**根因**：主进程只给主窗口设了 `icon`，其他窗口（更新窗口等）和所有 `dialog.show*`
都没带图标；Windows 任务栏还会按 `AppUserModelId` 归组，没设就用 `electron.exe` 的图标。

**改法**（`src/main/main.ts`）：
- 新增 `appIconPath()`：打包态取 `process.resourcesPath/icon.png`，开发态取 `build/icon.png`；
- `app.on('browser-window-created')` 给**每一个**新建窗口补图标；
- `app.setAppUserModelId('com.blockcanvas.app')` 在 `whenReady` 里、任何窗口创建之前设好；
- 所有 `dialog.showSaveDialog / showOpenDialog / showMessageBox` 统一走
  `showSaveDialog / showOpenDialog` 包装，**挂到主窗口上**（模态 + 继承窗口图标）。

> 说明：开发态下 `electron.exe` 自己的进程图标仍是 Electron 的原子图标，
> 这是宿主进程的图标，改不了；**打包后的 exe / 安装版**显示的是三色 Logo。
> 如果你在 `pnpm dev` 里看到原生对话框还是原子图标，那是这个原因，不是没修好。

设置页正文最宽 1080px，帮助中心正文保持 900px 上限并补了左右 32px 呼吸位，
超宽屏上不会把表单拉成一条长线。

## 三、请你这样体验（照着点，一条一条对）

5. 顶部标签栏：右侧那条技巧提示现在是**一行灰字**，没有边框，鼠标移上去才出现关闭按钮。

    - 选「绝对定位」，出现上/右/下/左四个偏移；
    - 点「水平居中」，元素应水平居中（需要它有明确宽度）；
    - 点「清除定位」，回到普通文档流。

### C. 只读快照预览（本轮新功能，重点体验）

    - 如果原工程正开着，切回去看，**画布已经是回退后的内容**，且没有未保存点；
