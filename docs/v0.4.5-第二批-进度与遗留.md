## 一、已完成（可立刻验收）

### P0 回归（我上一轮改出来的）

**R1 首页搜索框"点不进去"**
- 根因：搜索结果面板（`.eh-results`）**状态残留**。它挂在 `.eh-search` 里，
  挡住下面按钮时，点按钮的 mousedown 落在面板上 → 面板不关、按钮也点不到（死锁）。
- 修法（`EmptyHome.tsx`）：点面板空白处也关；窗口失焦关；Esc 关；
  组件挂载时清空查询词与焦点；`.eh-search` 提到 `z-index:4`；面板高度受视口限制。
- 验证：`probe-uiaudit` 新增 2 项——搜索框可聚焦、Esc 能收起面板。

**R2 "样式还没有名字"卡片变奇怪**
- 根因：卡片宽 376px，单行文字只分到 183px（需要 207px）→ 被截断成"样式还没有名字，…"。
- 修法：改成两行（标题 + 一句原因），按钮缩成「起名」「总览」，高度 44px。

### D 交互

**D2 属性搜索框 ↑↓ 导航**
- `AddPropertyMenu` 的搜索框现在支持 ↑↓ 在结果间移动（值命中排在前面、属性名按分组在后，按 DOM 顺序导航，索引永远和眼睛看到的一致）、Enter 直接插入、Esc 关闭；高亮用左侧 2px 强调条 + 淡底。

**D1 Alt 拖动"闪一下又回来"**
- 根因：先按住左键、过一会儿才按 Alt 时，拖拽锚点用的还是**按 Alt 之前**算的 `startX/startY`（可能还是 null），
  `dx/dy` 一下子变成几十像素 → 元素先跳到旧锚点、下一帧再弹回鼠标。
- 修法（`Canvas.tsx`）：进入拖动的那一帧**重新锚定**（起点对齐当前指针 + 当前 rect），并禁止在已有拖拽时重复起拖。

## 三、怎么验收这一轮

```bash

```

1. **首页**：点搜索框 → 能聚焦；输入 `zzz` 出现"没有找到"面板 → 按 **Esc** 收起 → 再点下面的「新建项目」按钮，应该**一次就点得动**（以前会被面板挡住）。
2. **首页**：故意点一下页面空白处，结果面板也应该收起。
3. **属性面板**：选中元素 → 顶部黄色提醒是**两行 44px**，右边「起名」「总览」两个小按钮，文字不再被截断。
4. **外轮廓卡片**：颜色那一行——`#2563eb` 输入框和蓝色色块**在同一行**；线型按钮四个字不再拆成"实/线"两行。
5. **背景卡片**：`纯色 | 渐变 | 图片` 三个页签；点「图片」→ 有缩略图、地址输入框、「本地图片…」按钮、铺满方式/位置/平铺三个下拉。
6. **任意颜色字段**：右侧有 `var` 按钮（新项目没有变量时也能点开，里面有新建指引）。
7. **快捷助手 → 定位助手**：
   - 四边偏移是**单列四行**，不再被切掉；
   - 默认流式时四边置灰并提示先选定位方式；选「相对定位」后可用；
   - 元素原本 margin 不对称时，点「水平居中」会先出现**黄色内联确认条**，在你选之前样式不会变。
8. **padding / margin**：每次打开都是**分边独立**，不再默认四边同步。
9. **添加属性菜单**：在搜索框里按 **↑ ↓** 高亮会上下移动，**Enter** 直接插入。
10. **Alt 拖动**：按住左键拖动元素、中途再按 Alt —— 元素**不会**再闪到别处又弹回来。
