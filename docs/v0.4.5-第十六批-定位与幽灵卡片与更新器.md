## 一、中键属性搜索：按用户新规则重做（逻辑简化）

**用户原话**（逐条）：
> 「中键选中元素现在逻辑太复杂了，改成下面这个，简单方便：
>  1. 输入框的结果只显示三个，每一个按照下面的显示：属性中文名称 属性英文名 最后末尾显示有没有添加。原来的属性值搜索和快捷添加不要了。
>  2. 如果 Enter 搜索列表中的选项，那么就是定位到搜索列表第一个属性，右侧菜单。
>  3. 搜索的 3 个结果中默认选中第一个，把这个卡片结果变成淡蓝色就行，左边的蓝色样式不要了。键盘按 ↓ 或者 ↑ 调整搜索到的 3 个结果的选中情况。
>  4. 如果搜索结果第一个是没有添加过的，那么按 Enter 就不能定位，按 Ctrl + Enter 添加并且定位。
>  5. 鼠标操作对应 左键：定位，不能添加：左键 + Enter 添加 + 定位」

| 规则 | 实现 |
| --- | --- |
| ① 只显示三个 | `MAX_HITS = 3`；每行 = 中文名（省略号）+ 英文名（等宽）+ 「已添加/未添加」徽章 |
| ① 值搜索/快捷添加删掉 | **整块移除** `.bc-prop-vals` / `.bc-prop-val` 与「属性 值」解析 |
| ② Enter = 定位第一条 | `commit(activeItem, ctrl)` → `bc:focus-prop` |
| ③ 默认选中第一条 + 淡蓝卡片底 | `activeIdx` 初值 0；选中态 `background: color-mix(accent 12%)`，**删掉** `inset 2px 0 0` 左侧蓝条 |
| ③ ↑↓ 切换 | 在 3 条里循环 |
| ④ 未添加 → Enter 无效 | 只给提示「还没添加 · 按 Ctrl+Enter 添加并定位」，框不关、不写样式 |
| ⑤ 左键定位 / Ctrl+左键添加 | 同一个 `commit()`，`e.ctrlKey || e.metaKey` |

探针：`probe-v045-batch16`（26 项）、`probe-v045-batch16b`、`probe-v045-batch8`（28 项）、`probe-prop-search`（18 项）。

## 二、三处「切换板块没有动画」

**用户原话**：
> 「注意右上角的页面设置，多个板块切换的时候没有动画。」
> 「全部项目上方的信息按钮没有关闭动画。」
> 「下方元素插入栏没有切换板块的动画。」

| 位置 | 根因 | 修法 |
| --- | --- | --- |
| 右上角页面设置（预设/渐变/图片/视频） | 条件渲染，切换即替换 | 包 `.eh-panel-tabbody` + `key={tab}` → 每次播 `bcSwapIn` |
| 元素插入栏（元素/模板/素材） | 同上 | 包 `.elem-tab-anim` + `key={tab}` |
| 项目信息小问号 | 只有进场、没有退场 | `useClosing(open, 160)` + `.pc-kindhelp-pop.is-closing` |
| 历史快照抽屉 | 同上 | `.pc-drawer-mask.is-closing` 显式 `animation: none` |

> **关键坑（都踩过）**：入场动画带 `both` 填充时，播完会**一直占着** `opacity/transform`
> —— 动画优先级高于普通声明与 `transition`，所以只写 `opacity: 0` 是**无效**的，
> 必须 `animation: none` 解除，退场过渡才真正生效。快照抽屉与小问号都是这个原因。

> **布局坑**：`.element-panel` 在底部布局下是 `flex-direction: row`，`.elem-main-wrap` / `.tpl-body`
> 靠 `flex: 1 1 0` 撑满。中间插一层包装 div 后它默认 `flex: 0 1 auto` → **整块内容挤到左边**（用户实测截图）。
> 包装层必须自己 `flex: 1 1 0` + `min-width: 0` + 纵向 flex，把"撑满"继续传下去。

## 三、更新器重写（用户实测失败的 4 条）

**用户原话**：
> 「1.弹出了很多个窗口然后关闭了 2.不会重新启动。
>  我希望只弹出一个窗口，然后内部写所有的操作，日志全部输出，输出到 data 里面。
>  同时更新的时候要把 BlockCanvas 主程序的上一级文件夹改名成 BlockCanvas，现在改不了。
>  完成后 .update 自动删除。现在跟以前的没区别，没做好。
>  我刚刚更新失败了：更新失败：ENOTEMPTY: directory not empty, rmdir '...\.update\staging\resources'」

| 问题 | 根因 | 修法 |
| --- | --- | --- |
| 弹很多窗口 | 用 `.bat`（必然开控制台 + `title`/`timeout`/`pause`），改名失败再弹 UAC + PowerShell，最后 `start exe` | **只生成一个 `.ps1`**，主进程用 `-WindowStyle Hidden` 拉起，全程零可见窗口 |
| 不重启 | 失败路径直接 `exit`，什么都不做 | 无论成功/失败**一定**重新拉起主程序（找不到就记日志） |
| 目录名改不了/改错 | 目标是 `<原名>-v<新版本>`，每更新一次变一次 | 新增 `canonicalFolderName()` → 固定收敛成 `BlockCanvas`（保留用户自起的后缀） |
| `.update` 删不掉 | 裸 `rmSync`，Windows 上句柄未释放就 `ENOTEMPTY` | 新增 `safeRmSync()`：`maxRetries: 8 / retryDelay: 250` + 逐层清空兜底 |
| 日志看不到 | 只有零散 `ulog` | 脚本内 `Log()` 函数全程写 `data/logs/update-YYYYMMDD.log`；遮罩里**实时滚动显示** |

**打包产物**（`build-exe.ps1`）：压缩前先做 `dist/.zip-stage/BlockCanvas/`，
压缩**这个目录本身** → 用户解压出来固定是 `BlockCanvas\BlockCanvas.exe`（不再是"解压到哪就叫什么"）。

**更新遮罩**（`App.tsx` 的 `UpdateBusyOverlay`）：新增可折叠的实时日志区（每秒读日志尾部、自动滚到底）
+ 「打开日志目录」按钮 —— 这就是用户要的"唯一一个窗口，内部写所有操作"。

## 四、定位系统（用户第 4~5 次反馈，逐条）

**用户原话**：
> 「1.默认流：现在基本可以了，除了上述的滚动页面抽搐
>  2.相对定位：可以了，但是原文档流位置这个字样跑到外面了，修一下。
>  然后反复说的：切换定位后要提示选择要不要清除 margin，不然原来的 margin 可能阻挡元素移动。
>  3.绝对定位：…为什么 left right top bottom 甚至能达到负数，不对。
>  并且我反复说的：不要同时给 top right bottom left 同时给数值，画布上就用两个，比如左上角区域就用 left top，不要 4 个都给。
>  4.固定定位 fixed：用不了，不知道为什么凭空出现空气墙，上下完全动不了…」

| # | 修法 |
| --- | --- |
| ② 原文档流位置字样跑外面 | 改成 `.pos-rel-note` 带图标 + `word-break: break-word` 的块，不再是裸文字 |
| ② 切换定位提示清 margin | 新增 `posSwitchAsk` 内联确认条：「清掉 margin 再切换 / 保留原 margin / 取消」 |
| ③ 偏移出现负数 | `sceneStore.updateStyle` 里统一钳制：**只对 absolute/fixed** 的 left/right/top/bottom 钳到 ≥0（relative/sticky 的负位移合法，不动） |
| ③④ 不要四边都给 | 定位界面从"四边各一格"改成**两根轴各一行**：横向「左/右」+ 一个数值，纵向「上/下」+ 一个数值；切换锚定边时另一边自动写 `auto` |
| ④ fixed 空气墙 | 见下节（Alt 滚轮/拖动） |

## 五、Alt 系列交互（用户明确分工）

**用户原话**：
> 「Alt + 滚轮不要触发页面上的盒模型显示；只有 Alt + 鼠标放到一个元素上 但不按住，
>  可以显示盒模型和定位等；Alt + 滚轮是精准定位。Alt + 左键按住元素是调整位置（现在是对的）。
>  Alt + 左键按住元素 + 滚轮就是滚动页面，但是现在元素不会跟手，会突然瞬移到上面或者下面。」

| 手势 | 行为 |
| --- | --- |
| Alt + 悬停（不按住） | 显示盒模型（F12 式读数）+ 可编辑虚线框 |
| Alt + 滚轮 | **精准微调位置**：1px / 格，Shift 加速 10px；期间**不弹盒模型**（`wheelNoBoxUntil` 挡 0.8s） |
| Alt + 按住拖动 | 调整位置（原有行为不变） |
| Alt + 拖动 + 滚轮 | 滚动画布，且**元素跟手** |
| Ctrl + 滚轮 | 缩放（Alt 让位给微调了） |

> 「元素突然瞬移」的根因：拖拽以"按下那一刻的屏幕 rect + 指针位移"为基准；
> 画布滚动 S 像素后元素整体上移 S，但基准 `d.rect` 还是旧的 → 目标位置凭空多出 S 的偏差。
> 修法：滚轮时把 `d.rect` 与纵向墙一起平移 S。

## 六、position「幽灵卡片」（用户澄清后的真实需求）

**用户原话**：
> 「幽灵卡片完全没有做，而且快捷助手开启了下方 css 属性不显示，但是对于定位 position 元素没有用。
>  而幽灵卡片就是临时的作用，比如中间选中元素输入 position，Enter 就可以直接定位到这个元素右侧的 position 的幽灵卡片，只是用来临时数据修改，避免去快捷助手里面改。」

- 上一轮我做的"快捷助手隐藏属性时的占位说明"（`.prop-ghost-card`）**已按用户要求删除**；

  并回车后，右侧**临时**弹出这张卡（蓝左边框 = 临时工具）：
  5 种定位方式一键切换、两根轴锚定、切换时问"要不要清 margin"、Esc / × 关闭。
