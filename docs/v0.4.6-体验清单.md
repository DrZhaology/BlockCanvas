# 设计大改（这一版新增，先看这个）

> 这一版按你提的七条设计规则重做了界面。下面每条都写了"看哪里、应该是什么样"。
> 全量探针 **61/61 通过**，桌面包 `dist\BlockCanvas-0.4.6-win64.zip`、网页版 `dist-web\index.html`。

**1｜连续曲率圆角**
- 看：按钮、卡片、弹窗的转角。应该是"润"的（曲率连续），不是正圆弧。
- 依据：内核升到 Chromium 140，用原生 `corner-shape: squircle`。画布里的**用户页面仍是普通圆角**（不能改你的稿子）。

**2｜不再盒子套盒子**
- 看：右侧快捷助手。以前四层边框，现在只剩输入框自己那层，其余用留白 + 细分隔线。
- 看：临时卡片（中键搜属性时出现）——紫底、**无边框无阴影**，长在「CSS 样式属性」列表里。

**3｜颜色收敛**
- 看：普通卡片一律白/极浅灰；主色只给"这一屏最该点的那个"。
- ⚠ 全站色板收敛**只做了一半**（规范已写下，没有逐屏改），下一轮继续。

**4｜滚动条自己画**
- 看：任意面板右侧/底部。应该是 3px 圆角长条，**静止也在**（很淡），滚动时变实，悬停加粗，可按住拖。
- 看：上排工具栏**不该再冒原生粗横条**。

**5｜窗口**
- 看：最上面那条是自绘的（logo + 文件/编辑/视图/帮助/设置 + 三个窗口按钮），**悬停有高亮、点一下弹原生菜单**。
- 看：窗口四周 **1px 主题色描边**（取你 Windows 的强调色），不再是"整条顶栏涂色"。
- 看：项目中心 / 设置 / 帮助 / 更新中心这些全屏页，**顶部按钮不再被压住**。

**6｜fixed 与定位（这块改动最大）**
- 选中 fixed 元素时，画布上出现**红色「浏览器视口」框**；它的**底边 = 底部元素面板的上沿**。
- Alt 拖动 fixed 元素：只能在框内动；**只写两条偏移**（拖动时自动把多出来的 left/right/top/bottom 收成两条）。
- 定位助手：四条边各带复选框（勾上才能拖/改），**最多一条 X + 一条 Y**，另有四个角一键预设。
- 「水平居中 / 垂直居中」= **钉死一维**，勾上后那条轴的复选框禁用，另一条轴照样能拖。
- 改 `position` 时弹**全屏模态**（先不设置 / 保留外边距 / **清除外边距**·绿色推荐），快捷助手和 CSS 属性行的下拉走同一个模态。

**7｜中键搜索**
- 中键搜到属性 → 该行**整行底色闪两下**（不再有那个上下两条橙线）。
- 「显示到下方 CSS 属性」**默认关闭**；关着时搜到的属性出现在**临时卡片**里（无 ×，换元素自动消失）。

**8｜竖屏 / 窄屏**
- 抽屉把手变成**贴边窄条**（26×48，手指可点范围仍 ≥44）。
- 从屏幕**左右边缘往内滑**可开抽屉（热区 28px，不只按钮）；抽屉里**往边缘滑**可关；竖滑不会误开。
- 抽屉开着时把手隐藏。**长按把手**可上下挪（±2.5% 吸附对齐），**双击**复位。
- 工具栏在竖屏下**折成两行**（设备/缩放/更多在第一行），不再横向滚。
- 设置 → 编辑器与画布 → 竖屏组：**抽屉方位**四选（左右分布 / 反向 / 都靠左 / 都靠右）。
- 首页在 360px 下不再文字溢出、页面设置面板不出界。

# 第一部分 · 先验"最容易出事"的（15 分钟）

这几项是本轮改动最大、也最容易手感出问题的地方。

## A. fixed 的"空气墙"（R6-16）

> 这是本轮最需要你确认的一项，因为它的行为**和以前不一样了**。

**A1｜新工程默认有 900px 首屏高度**
- 怎么验：新建工程 → 什么都不插
- 该看到：画布至少 900px 高（一屏），**看不到**首屏虚线
- 逻辑：内容没超过一屏时，画布底就是首屏底
- 【这个没看懂，感觉应该对的】

**A2｜内容超过一屏后出现"首屏线"**
- 怎么验：插一个大 div（我给个快办法：选中元素 → 属性面板加 `height: 2400px`）
- 该看到：画布变长到 2400px+，在 **900px 处出现一条蓝色虚线**，右端有标签「首屏 900px」
- 该看到：这条线**挡不住鼠标**（点它、拖它都没反应，能透过它选中下面的元素）
- 【✔】

**A3｜fixed 元素往下拖，停在首屏线不再越界**
- 怎么验：插一个 div → 定位方式选「固定 (fixed)」→ 按住 Alt 拖它的中间往下拖到最底
- 该看到：元素**停在首屏线附近**，不会跑到 2400px 的地方去
- 【我觉得这个设计有问题，我插入的div已经在刚刚那个2400px的div的下面了，那么我改成fixed，直接乱了，移动完全不对。设计有问题。】

> 我的解决方案：把浏览器的视口，在画布内部做成一个也是固定的像浏览器一样的视口：画布的左右就是左边缘和右边缘，上下边缘根据工具栏的变化始终变化。在工具栏下面，下方插入元素面板的上面，面板变了，这个视口也变。视口始终固定。呈现矩形，工具栏打开边框选项可以显示这个视口：固定红色。Alt的时候，fixed的元素就只能在这个视口内部移动。同时不会触发画布的上下滚动。
同时fixed的top right left bottom的逻辑说过很多次了，你没改。而且我觉得原来的那个自动使用两个定位的也有点问题。所以按照下面的，虽然麻烦但是非常稳定，也不是原来的4个定位的值都要写，浏览器的视口和画布内定义的视口长和宽都不一样，所以会打架。画布内和浏览器内的完全不一样。
定位助手fixed的时候，单独显示 top right left bottom四个元素，前面是选择框，没有选中的话，Alt不能拖动，也不能直接改数值。鼠标能点击选中前面的复选框，点击后这个属性就解锁了，比如left，解锁后你能够Alt左右拖动元素，能改left的数值。4个属性可以单独解锁，但是最多只能解锁两个，并且解锁的两个有要求，只能解锁下面的组合：left top,left bottomo,right top,right bottom，对应矩形的四个内角。Alt能在这个画布内自由拖动（解锁了两个属性的组合）的时候，用两边的定位最稳。
如果用户不懂怎么选择，可能也不清楚4种复选的选择。做一个选择框：左上角，左下角，右上角，右下角。选择后自动选择4个定位属性的开启关闭。
另外，横向对其和竖向对齐也做一下（画布的中间横线和竖向中线），是选择框，但是这个和上面的单独设置4个属性的属性值有一些联系：设置了这个对齐，上面的这个就不可以设置了。设置了对齐的时候，相当于钉死在1维了，上下或左右的移动还是做好。同时top bottom不能同时开，right和left也不能开。
不理解可以问我，我觉得这个方案基本够了，也比较稳定。

> 还有一个重要的问题，你必须知道：改position的时候，定一条死规矩，必须清除margin，不然特别麻烦，现在程序我从正常的文档流切换到fixed的时候，确实清楚的margin，都是0，但是没有提示。一定要做一下提示。全屏的medal提示（这种弹窗应该叫medal，可能会叫错了）。说明为什么要清除margin，说明这样方便定位调整，不会被margin限制。有三个选项，先不设置定位，保留外边距并切换定位，清除外边距并切换定位。颜色要鲜明，最后的第三个按钮用绿色或者类似的颜色，提醒用户这个建议点击，这个好。
后面我发现有些地方做了，但是有些时候改的时候不会有提示，比如卡片position直接改，这次做统一。

这里我的描述可能非常难理解，你要多问问题确定。
**A4｜短页面下会写成 `bottom: 0px`**
- 怎么验：清掉那个超高 div（画布回到一屏高）→ fixed 元素拖到首屏底
- 该看到：定位偏移变成 `bottom: 0px`（不是 `top: 623px` 之类）
- 【按照上面的改】

**A5｜长页面下不写** `bottom: 0px`（这是有意的）
- 怎么验：同上，但把画布撑到 2400px 再拖 fixed 到底
- 该看到：**偏移仍是数值**（比如 `top: 802px`），**不是** `bottom: 0px`
- **为什么这样设计**：画布本身就是 fixed 的参照物，如果写 `bottom: 0`，
  它会解析成"画布底"——你会在松手瞬间看到元素**飞到几千米外**。
  所以长页面保留数值，位置纹丝不动。
- 【 】

**A6｜「首屏高度」可改，改了线跟着走**
- 怎么验：属性面板 → 页面页签 → body 设置 → 找到「首屏高度」
- 该看到：默认 900，改成 1200 后 → 首屏线上移到 1200px，画布最小高度也跟着变
- 该看到：这一项**不会**进导出的 HTML（只是编辑器辅助）
- 【 】
