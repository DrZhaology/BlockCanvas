# 第一部分 · 先验"最容易出事"的（15 分钟）

这几项是本轮改动最大、也最容易手感出问题的地方。

## A. fixed 的"空气墙"（R6-16）

> 这是本轮最需要你确认的一项，因为它的行为**和以前不一样了**。

**A1｜新工程默认有 900px 首屏高度**
- 怎么验：新建工程 → 什么都不插
- 该看到：画布至少 900px 高（一屏），**看不到**首屏虚线
- 逻辑：内容没超过一屏时，画布底就是首屏底
- 【 】

**A2｜内容超过一屏后出现"首屏线"**
- 怎么验：插一个大 div（我给个快办法：选中元素 → 属性面板加 `height: 2400px`）
- 该看到：画布变长到 2400px+，在 **900px 处出现一条蓝色虚线**，右端有标签「首屏 900px」
- 该看到：这条线**挡不住鼠标**（点它、拖它都没反应，能透过它选中下面的元素）
- 【 】

**A3｜fixed 元素往下拖，停在首屏线不再越界**
- 怎么验：插一个 div → 定位方式选「固定 (fixed)」→ 按住 Alt 拖它的中间往下拖到最底
- 该看到：元素**停在首屏线附近**，不会跑到 2400px 的地方去
- 【 】

**A4｜短页面下会写成 `bottom: 0px`**
- 怎么验：清掉那个超高 div（画布回到一屏高）→ fixed 元素拖到首屏底
- 该看到：定位偏移变成 `bottom: 0px`（不是 `top: 623px` 之类）
- 【 】

**A5｜长页面下**不写** `bottom: 0px`（这是有意的）**
- 怎么验：同上，但把画布撑到 2400px 再拖 fixed 到底
- 该看到：**偏移仍是数值**（比如 `top: 802px`），**不是** `bottom: 0px`
- **为什么这样设计**：画布本身就是 fixed 的参照物，如果写 `bottom: 0`，
  它会解析成"画布底"——你会在松手瞬间看到元素**飞到几千米外**。
  所以长页面保留数值，位置纹丝不动。
- 【 】

**A6｜「首屏高度」可改，改了线跟着走**
- 怎么验：属性面板 → 页面页签 → body 设置 → 找到「首屏高度」
- 该看到：默认 900，改成 1200 后 → 首屏线上移到 1200px，画布最小高度也跟着变
- 该看到：这一项**不会**进导出的 HTML（只是编辑器辅助）
- 【 】

## B. sticky 可视化（R6-17）

**B1｜sticky 元素有角标**
- 怎么验：插 div → 快速助手 → 定位助手 → 选「粘性定位 (sticky)」
- 该看到：元素左上角出现紫色角标
- 【 】

**B2｜没写吸附距离时是**橙色警示**（最重要的提示）**
- 怎么验：切到 sticky 但 top/bottom 都空着
- 该看到：角标变成**橙色**，写「粘 未设距离」
- 该看到：快捷助手里有一条黄色提示：「还没设吸附距离 —— 没有 top / bottom 的话，sticky 永远不会吸附」
- **为什么强调**：这是最常见的错（设了 sticky 以为会粘，其实永远不粘）
- 【 】

**B3｜写了吸附距离后变成 armed**
- 怎么验：纵向锚定填 `top` + `20px`
- 该看到：角标变紫，写「粘 距上 20px」，元素顶部多一条紫色**虚线**
- 该看到：黄色提示变成紫色说明：「会吸附：滚动到距顶部 20px 处挂住」
- 【 】

**B4｜普通元素不被打扰**
- 怎么验：随便看几个普通 div / p
- 该看到：**没有任何角标**
- 【 】

**B5｜我记得你要的是"真实滚动预览"，这一版**没做**（重要，请确认方向）**
- 现在的做法：只把"会不会吸附、以什么为线"说清楚，**不模拟滚动**
- **为什么没做**：画布外面套着 `transform: scale(zoom)`，在里面再造滚动上下文
  一定和真实浏览器不完全一致 —— 我宁可给准确信息，不给"看起来像但不可信"的预览
- 想问你的：**这样够用吗？** 还是你确实需要"拖着滚一下看它粘住"？
  （真要做的话成本不小，而且会有"画布上粘住了、导出后不粘"的风险）
- 【 够用 / 需要真模拟（原因：________） 】

## C. 视频编码（R6-18）

**C1｜HEVC（H.265）视频不再白屏，改成明确提示**
- 前提：你手上有 HEVC 的视频（**iPhone / 苹果设备导出的 mp4 基本都是**）
- 怎么验：插一个 video 元素 → 选那个 HEVC 文件
- 该看到：画布上**不是白屏**，而是黄色斜纹块，写「视频编码不支持 / hvc1 · 转成 H.264 后可预览」
- 该看到：属性面板出现警告卡，说明这是 H.265、并给转换建议
- 【 】

**C2｜H.264 视频照常播放（不能被误伤）**
- 怎么验：换一个普通的 H.264 mp4
- 该看到：正常显示画面，能播放
- 【 】

**C3｜编码读不出来的视频，仍然尝试播放（不能误杀）**
- 怎么验：随便一个不太常规的视频（分片 mp4、老格式都行）
- 该看到：如果实在解不了 → 白屏/黑屏（浏览器行为），但**不显示**"编码不支持"黄块
- 逻辑：探测失败 ≠ 视频坏，宁可放它试，也不误判
- 【 没有这类文件可跳过 ➖ 】

**C4｜首页背景视频也走同一套预检**
- 怎么验：关掉所有标签 → 空首页 → 页面设置 → 背景 → 视频 → 选 HEVC 文件
- 该看到：立刻提示"编码解不了 + 转换建议"，**不会**先黑一下再退回
- 【 】
