1. **View Transition 在无 GPU / 软件渲染环境会让 GPU 进程崩溃**（`GPU process isn't usable. Goodbye.`）。
   已在"关标签"处移除 VT；`switchView` / 打开工程仍保留。若探针出现 `Target page closed`，
   先看是不是 VT + 无 GPU 叠加；可临时去掉对应 VT 复测。
2. **探针不要在跑的时候 `pnpm build`**：会替换 `out/`，正在运行的 Electron 直接崩。
3. `probe-storage` 偶发"系统 Temp 文件识别 0"——并行/残留临时文件竞争，单跑必过，不算回归。
4. 终端显示中文乱码是 PowerShell 代码页问题，**读文件请用 read 工具**，不要用 `Get-Content` 判断编码。

## 2. 剩余大件的设计要点（下次直接照这个做）

### 2.1 快照特殊标签页（优先级最高）

- 标签类型：`kind: 'snapshot'`，带 `sourceProjectPath` + `snapshotId`；**不可保存**（Ctrl+S 禁用/提示）。
- 视觉：标签底色与普通工程不同（例如淡紫/斜纹），带相机图标；关闭时**不**提示保存。
- 只读：画布可选中、可看右侧属性，但所有输入/拖拽/右键修改入口禁用（`readonly` 上下文，或 store 层拦截写入）。
- 操作入口（快照标签顶部工具条）：
  - **覆盖到项目**（危险操作：二次确认 + 提示会替换当前工程，先自动存一份当前快照）；
  - **另存为新项目**（走保存对话框，默认名 `<项目名>-快照-<时间>`）；
  - **退出预览**（回到原标签）。
- 回退告知：任何"从快照恢复"动作完成后，用程序内 toast/确认框明确告知"已回退到 X 时间的快照"。

### 2.2 素材（图片 / 视频 / 音频）

- 工程 zip 内新增 `assets/` 目录，原样存二进制（**不要 base64**）；工程文件里记录 `assetId → 相对条目名`。
- 图片元素：`src` 仍是用户填的 URL/相对/绝对路径；若本地存在则优先本地，否则回退 zip 内素材；
  右侧显示"本地已找到 / 使用工程内素材"状态（勾/提示）。
- 新增「图库」页面：导入（多选）、预览、复制 URL、删除（被引用时提示 N 处）。
- 视频/音频：元素面板新增 `video` / `audio`；插入后默认 `controls`；
  右侧只显示音视频相关属性（尺寸/对象适配/圆角/阴影/边框/自动播放/循环/静音/封面），
  不显示文字排版等无关属性（按 `onlyTypes` 分组）。

### 2.3 外部工程 / 多页 / 路径基准

- 工程登记：`data/projects.json`（或 app config）记录 `{ filePath, absPath, relPath, name, lastOpened }`；
  `project:list` 合并 `data/projects` 与登记表，去重。
- 损坏处理：读取失败 → 列表项标红叉 + 原因；若该工程有快照，提供"用快照恢复"。
- 多页：工程根下 `pages/*.html` + `styles/*.css`；先在 UI 里做"页面列表 + CSS 复用（共享样式表）"，
  导出时按页生成 HTML、公共 CSS 单独成文件。
- 路径基准：`pathBase: { mode: 'project' } | { mode: 'file'|'folder', absPath, hiddenKey }`；
  解析时先按基准，再回退工程目录；`hiddenKey` 静默存进工程文件，不在 UI 展示。

### 2.4 变量面板 / 字体 / 定位助手 / 阴影

- 变量行改成与元素 CSS 相同的卡片（值编辑器按 kind 用取色盘/数值/阴影），
  **变量名始终可编辑**（行内 input，失焦提交、重名提示、引用同步改）。
- 字体：先做「可商用预置」清单（思源黑体 / Noto Sans SC / 文泉驿等），
  预览必须各自用自己的 `font-family`；是否随包分发字体文件需要用户拍板（体积 vs 一致性）。
- 快捷助手新增「定位助手」：left/top/right/bottom + 水平/垂直居中一键，带"显示到下方 CSS"开关。
- 阴影卡片：颜色行用取色盘 + 实时预览；预览卡片背景不要用选中橙框干扰。

### 2.5 深色模式插件化

- 现有程序内深色入口（设置 → 个性化与外观）隐藏/移除；
- 深色模式能力放进 `extensions/plugins/dark-mode/`，`manifest.version = "1.0"`；
- 插件内 Emoji 全部换 SVG（复用主程序图标风格，或插件自带 1~2 色线性图标）；
- 需要写一份「插件 vs 内置」的优缺点分析（加载隔离、更新独立、能力边界、调试成本）。

### 2.6 更新器（Windows / macOS / Linux）

- 统一流程：下载 → 校验 → 关闭所有 BlockCanvas 进程 → 解压/替换 → 改名目录（`BlockCanvas-v<版本>`）→ 重启。
- **只开一个命令行窗口**，逐步输出；输出同时写 `data/logs/update-<时间>.log`；设置里可查看/清理。
- 临时脚本放 `data/tmp/`（Windows 可放 `%TEMP%` 但需清理）。
- 平台差异：
  - Windows：PowerShell 脚本 + UAC 提权；
  - macOS：`.app` 替换（注意 Gatekeeper/quarantine，必要时 `xattr -dr com.apple.quarantine`）；
  - Linux：AppImage 替换 或 解压目录替换（需确认发行形态）。
- 更新前必须 `taskkill` / `pkill` 掉所有实例，否则文件占用。
