## 一、已修（可立刻验收）

### 1. 提示卡片前面的 SVG 歪了
- 真因：`13-polish-v040.css` 给 `.cls-warn-ico` 设的是 28px 圆角方块 + `display:grid; place-items:center`，
  我上一批把它覆盖成 `inline-flex` —— **`place-items` 对 inline-flex 不生效**，
  图标就贴到左上角，看起来像"歪了"。
- 修法：恢复 `display:grid; place-items:center`，尺寸 26px，`svg { display:block }`。

### 2. 选中元素后右侧面板总跳回「元素」
- 修法：`Inspector` 里监听 `scene.selectedId`，一变就 `setInspectorTabRaw('element')`。
- 效果：不管当前停在「类名 / 页面 / 变量」，点画布上任何元素都立刻回到元素属性。

### 3. 调模糊度时右侧冒出滚动条 + 整页轻微上下滑（抽搐）
- 真因：我上一批把 `.empty-home` 改成了 `overflow-y:auto`。媒体背景加了 `filter: blur()` 之后，
  绘制范围会外扩并被算进滚动区域 → 滚动条出现、面板一动就抖。
- 修法：`.empty-home` 改回 `overflow:hidden`（整体裁切）；
  右侧设置面板自己限高并内部滚动（`.eh-panel { max-height: calc(100vh - 64px); overflow-y:auto }`）。

### 4. 首页渐变：设完色标颜色，设置面板被关掉
- 真因：调色盘 / 变量菜单都是 `createPortal` 挂到 `body` 的，
  点它们算"点在面板外面" → 面板关闭。
- 修法：面板的"点外部关闭"逻辑排除调色盘体系（`.cp-modal` / `.cp-varmenu` / `.cp-sv` / `.cp-hue` / `.cp-alpha` 等）。

### 5. 文档搜索结果：跳到屏幕中间 + 黄色荧光笔闪一下
- 修法：`HelpCenter` 新增 `centerAndFlash()`：
  滚动位置按"元素居中"算（`offsetTop - (视口高 - 元素高)/2`），
  并给落点加 `.bc-doc-hit` 类，黄色荧光笔底纹 + 轻微脉冲，2.6 秒后自动移除。
- 覆盖两条路径：主界面搜索点文档结果、帮助中心内的搜索结果。

### 6. 添加 / 删除属性卡片动画
- **添加**：只有"刚加的那一行"（`.is-just-added`）从右侧面板外滑入（`translateX(34px)` + 轻微缩放），
  0.26s `cubic-bezier(0.22,1,0.36,1)`，不会整个列表一起动。
- **删除**：点 × 时先给行加 `.is-leaving`，向右滑出 + 收起高度，170ms 后才真正删除。
- 都尊重系统「减少动态效果」。

### 7. 属性名前的"父级"标签 & 未命名提醒（上一批的收尾）
- 未命名提醒图标恢复居中（同第 1 条）；卡片保持两行 44px。

## 二、没做完（下一轮）

### A. 变量系统（你提的三点，一个都没改）
1. **名称自由度不够**：现在只允许小写字母/数字/连字符。
2. **强制加 `bc` 前缀**：界面显示 `primary`，导出的 CSS 却是 `var(--bc-primary)`。
3. **margin / padding 不能用变量**：四值输入框只接受数值，没有 var 入口。

> 为什么没动：这三条要改 `designTokens.ts` 的命名/校验/序列化 + `TrblInput` 的值模型
> （现在四值输入假定"数值+单位"，要支持 `var(--x)` 就得允许纯文本并跳过数值解析），
> 而且改前缀会影响**已存工程的 `var(--bc-*)` 引用**，需要迁移策略。
> 我不想在没验证迁移的情况下把老工程引用改坏，所以留到单独一轮做。

## 三、验收步骤

```bash
pnpm dev
```

1. **首页**：选中一个元素前先看首页——**右侧不应该出现滚动条**；打开设置 → 图片/视频壁纸 → 拖"模糊"滑块，页面**不再上下抖动**。
2. **首页渐变**：点色标 → 打开调色盘 → 选颜色 → **设置面板仍然开着**（以前会关）。
3. **首页搜索**：搜一个文档关键词 → 点结果 → 目标段落应停在**屏幕正中**，并有一层**黄色荧光笔**底纹闪约 2.6 秒。
4. **属性面板**：先把右侧切到「类名」页签 → 点画布上任意元素 → 应**自动跳回「元素」**。
5. **属性面板**：点「+ 添加属性」加一个 → 新卡片**从右侧滑入**；点卡片右上角 × → 卡片**向右滑出**再消失。
6. **未命名提醒**：黄色卡片左侧的警告图标应**居中**在圆角方块里（不再偏）。

自动验收：`node tests/e2e/probe-uiaudit.mjs`（23 项）、`node tests/e2e/probe-v045b-cards.mjs`（5 项）
