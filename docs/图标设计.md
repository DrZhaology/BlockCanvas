# BlockCanvas 积木画布 · 图标设计

> 设计日期：2026-08-16
> 设计者：BlockCanvas（用户口述方向 + 开发实现）
> 交付物：SVG 源文件 + 各尺寸 PNG + 窗口图标 + 界面展示

---

## 一、设计理念

一句话：**「三块彩色积木拼出一个 L，就是一张画布。」**

BlockCanvas 的定位是「给零基础用户的可视化网页工厂」，产物是干净可读的 HTML / CSS / JS。Logo 要同时传达两层含义：

1. **积木（Block）**：用三块小方块拼接，呼应「积木画布」这个名字，也暗合后期要接入的 Scratch 式积木编程。
2. **Web 三件套**：三块方块的颜色直接取自代表 Web 技术的三种经典颜色 —— 这就是产品要做的事。

## 二、形状与颜色

三块**圆角小方块**构成一个 **「L」形**（2×2 网格里缺右上角一格，更显「待拼接的积木/画布」的现代感）：

```
■ ·
■ ■
```

| 位置 | 颜色 | 代表 | 色值 |
|---|---|---|---|
| 左上 | 蓝 | CSS | `#2965F1` |
| 左下 | 橙 | HTML | `#E34F26` |
| 右下 | 黄 | JavaScript | `#F7DF1E` |

- 每块方块尺寸一致（92×92，viewBox 256），圆角 20px，方块之间留 14px 空隙，读成「三块独立积木」。
- 背景透明，可自由叠到浅色 / 深色场景；**无渐变、无描边、无多余装饰**，符合「简单、不要花里胡哨」。

## 三、文件清单

| 文件 | 用途 |
|---|---|
| `src/renderer/assets/logo.svg` | 主 Logo（矢量、透明背景），界面展示与二次导出的源 |
| `src/renderer/assets/logo-*.png` | 各尺寸位图（512/256/128/64/48/32/16），用于窗口图标、favicon、未来打包 |

## 四、使用场景

- **界面**：应用标题栏 /「关于」弹窗中展示主 Logo（已接入 `ui` 层）。
- **窗口图标**：Electron `BrowserWindow.icon`（用 PNG）。
- **未来打包**（阶段 6）：`electron-builder` 需 `.ico`，届时由 `logo.svg` 导出。

## 五、重新生成

PNG 由 `logo.svg` 通过 Electron/Chromium 离屏渲染导出，脚本见 `tools/render-logo.mjs`。
若调整颜色或方块比例，只改 `logo.svg`，再跑脚本即可同步更新所有 PNG。
