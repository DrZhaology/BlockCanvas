## 0. 五分钟上手

1. 打开软件，默认在「编辑器」视图。下方是**元素面板**，中间是**画布**，右边是**属性面板**。
2. 在元素面板点一下「通用容器」→ 画布上就出现一个盒子（默认铺满宽度）。
3. 在元素面板点一下「标题1」→ 出现一个 `h1`。
4. 选中 `h1`，在**双击**它可以直接改文字；右侧属性面板改字号、颜色、对齐。
5. 重复"插入 → 选中 → 右边调数值"，把界面搭出来。
6. 点工具栏的「预览」看真实效果，点「导出 HTML」保存成网页文件。

> 记住一句话：**下方插入 → 中间选中 → 右边调数值**。其余交互都是这条主线的加速器。

## 1. 界面总览

编辑器从上到下、从左到右分成五块：

| 区域 | 位置 | 作用 |
|---|---|---|
| 项目标签栏 | 最顶部 | 像浏览器一样管理多个工程标签页 |
| 工具栏 | 标签栏下方 | 编辑 / 视图 / 检查 / 输出 / 任务 / 更多 |
| 元素面板 | 下方或左侧（可切换） | 插入元素、浏览模板库 |
| 画布 | 正中 | 所见即所得地摆放元素 |
| 属性面板 | 右侧 | 调整选中元素的一切样式 |

### 1.1 顶部项目标签栏

- 每个标签 = 一个打开的工程页面，**会话自动恢复**：关掉软件再打开，标签还在。
- 标签上有"未保存小圆点 `•`"，鼠标移上去会变成关闭按钮 `×`。
- 关闭保护：**完全空且没动过**的标签，点 `×` 直接关；只要编辑过（撤销栈非空），会弹窗二次确认，避免误删。
- 末尾的 `＋` 新建一个空白标签页。
- 标签栏右端是「**使用手册（?）**」入口和「**小技巧**」轮播（每 15 秒换一条，双击文字立刻换下一条）。

### 1.2 工具栏

工具栏按钮分成四个语义区，段间用竖线分隔，右端是固定区：

- **编辑**：复制 / 剪切 / 粘贴 / 副本 / 删除（出厂折成「剪贴板」工具组）。
- **视图**：画布宽度 / 缩放 / 轮廓（同类同色描边）/ 设备切换（电脑 / 平板 / 手机）。
  - 工具栏上的「**设备**」按钮**图标会跟着当前画布宽度实时变**（电脑 / 平板 / 手机三种线性图标）——
    连**窗口变窄**（自适应画布跟着变窄）也会实时切换；鼠标浮上去展开的浮层右侧会显示「当前：设备 · 宽度」。
- **检查**：类名检查 / 导出元素模板 / 取消选中。
- **输出**：预览 / 全部项目 / 导出 HTML / 设置。
- **右端固定区**：常驻的手边工具 + 「**任务**」按钮 + 「**⋯ 更多**」按钮。

要点：

- 主区与右区都能**横向滚动**，竖向滚轮即可左右滚，不必按 Shift。
- 每个按钮放在哪个区、什么顺序，都能在「**设置 → 工具栏管理**」里拖拽调整。
- 多个按钮可以打包成**工具组**（鼠标悬浮即展开组内工具）。
- 「**⋯ 更多**」的左边是常驻的「**任务**」按钮（见第 9 节）。
- **插件注册的工具栏按钮只能进「⋯ 更多」**；想放到主区/右区，用「设置 → 工具栏管理」里每个区域右端的「**＋ 插入按钮**」。

### 1.3 元素面板（下方 / 左侧）

两个页签：

- **元素**：按类别列出所有可插入的 HTML 元素（见第 2 节）。
- **模板**：内置模板资源库，按分类展示，一键插入整页或组件（见第 2 节）。

顶部有「撑开口袋」按钮：点一下把面板撑大，方便一次浏览很多模板；再点收拢。

### 1.4 画布

- 画布 = 真实网页的 `body`。插入的元素按**流式布局**从上往下堆叠。
- 画布外的灰色斜纹区可以滚动；拖动左右边缘的手柄可调整画布宽度。
- 选中元素后有蓝色描边框；行内元素（span/a 等）跨行时显示一个合并外框。
- 顶部有**设备切换条**：电脑 / 平板 / 手机，切换 = 改画布宽度 = 改编辑断点，**未选中元素时也能用**。

### 1.5 属性面板（右侧）

顶部两个页签：**图层** 与 **属性**。属性面板分多个可折叠板块（见第 4 节）。所有折叠状态都会记住。

### 1.6 面板尺寸

三条分割线都能拖动：底部面板高度、右侧面板宽度、左侧面板宽度（左/下布局不同时出现）。尺寸自动记住。

### 1.7 首页（没有打开任何工程时）

**启动软件时不会自动塞一个「未命名项目 1」**：没有标签就直接进首页，关掉最后一个标签也会回到这里。
首页做成浏览器"新标签页"的样子，所有组件统一偏上：

- **搜索框**：同时搜「本地工程」和「三份内置文档」（项目介绍 / 使用手册 / 开发历程）。
  结果分两组，`↑` `↓` 选择、`Enter` 打开、`Esc` 清空；点文档结果会直接打开帮助中心并跳到对应章节。
- **三个快捷入口**：打开工程 / 新建项目 / 全部项目。
- **最近打开**：按修改时间列最近 6 个工程，点一下直接打开。
- **右上角只有一枚齿轮**（不写文字），点开是「页面设置」：
  - **预设**：8 个预置背景 + 自定义纯色；保存过的图片 / 视频背景会显示**缩略图**（视频带播放角标）；
  - **渐变**：和画布「背景颜色 → 渐变」是**同一个编辑器**（色标、拖动排序、方向盘角度、预制配色），
    改动实时生效；
  - **图片 / 视频**：填相对路径、绝对路径或 https 链接，也可以点「选择」挑本地文件；
    **填了/选了就立即生效**（没有「应用」按钮），「遮罩」与「模糊」两个滑块实时调整；
  - **文字自动反色**：背景偏暗（图片 / 视频会实时采样）时，标题、搜索框、按钮、卡片自动转白；
  - 视频支持 mp4 / webm / ogv，可以拖进度；窗口不可见时**自动暂停**，不空转显卡。
- 背景只影响这个首页，**不会进入工程导出**；离开首页时内容淡出、背景保持（不会整窗变白），
  回来时淡入。启动时会等上次会话读完再渲染，不会"先首页再闪到画布"。

## 2. 元素面板

### 2.1 元素页

按类别分组，点一下即插入到当前选中元素内部（没选中则插到最外层）：

| 分类 | 元素 |
|---|---|
| 容器 | 通用容器 `div`、区块 `section`、页眉 `header`、导航 `nav`、主区 `main`、文章 `article`、侧栏 `aside`、图文块 `figure`、页脚 `footer` |
| 标题与段落 | 标题1~4 `h1~h4`、段落 `p`、引用块 `blockquote` |
| 行内文字 | 行内文字 `span`、重点加粗 `strong`、斜体 `em`、高亮 `mark`、小字 `small`、代码 `code`、删除线 `del`、链接 `a` |
| 列表 | 无序列表 `ul`、有序列表 `ol`、列表项 `li` |
| 表格 | 表格 `table`、表格行 `tr`、表头格 `th`、单元格 `td` |
| 表单与交互 | 按钮 `button`、输入框 `input`、文本域 `textarea`、标签文字 `label`、表单容器 `form` |
| 多媒体与其他 | 图片 `img`、图注 `figcaption`、分割线 `hr`、换行 `br` |

- 每个按钮**悬停 0.5 秒**会弹出一张讲解卡：`<标签>` + 作用 + 放哪。
- 展示模式可切换：中文名 / 代码标签 / 两者都显示。
- 新插入的**表格自带默认预设样式**，不再是"光板"。
- 插件注册的元素类型也会出现在这里（带 `has-tag` 标记）。

### 2.2 模板页

- 内置 **14 个完整网页模板**（品牌首页 / 营销转化 / 信息内容 / 基础组件），按分类展示。
- 每个模板卡片是**运行时真实渲染的缩略图**（不是截图）。
- 顶部搜索框按"模板名 / 描述 / 资源包 / 分类"过滤。
- **左键点**卡片 = 插入到画布；**右键** = 打开预览大图（可滚动看细节，`Esc` 关闭）。

## 3. 画布操作

### 3.1 选中与多选

| 操作 | 效果 |
|---|---|
| 左键点元素 | 选中它 |
| `Ctrl` + 点元素 | 加选 / 减选（多选） |
| `Alt` + 点元素 | 选中它的**父级** |
| 空白 / 斜纹处按住拖动 | **框选**（矩形选框） |
| `Ctrl` + 拖框 | 把框到的元素**并入**当前选区 |
| `Ctrl + A` | 选中画布上所有顶层元素 |
| `Esc` | 取消选中 |

- 框选判定：元素**完全落在**选框内才被选中（和 Windows 桌面框选一致）。
- 锁定元素不参与选中。

### 3.2 框选视口外的内容（自动滚动）

- 拖动选框时，把鼠标**移到画布区的上/下（或左/右）边缘**，画布会**自动滚动**。
- 选框锚定在**画布内容**上，滚出去的部分也能被框进来，不会因为滚动而错位。
- 松开鼠标即完成选中。

### 3.3 双击改文字

- 双击**文字元素**（`h1`/`p`/`button`/`a`/`th`/`td` 等）→ 就地出现**多行编辑框**，直接改文案。
  - 编辑框会自动撑高，长文本、多行都能完整看到（不会只显示一小条）。
  - **点别的地方就自动保存**；**`Esc` 也是保存**（不是放弃）。
  - **`Enter` = 换行**（导出时自动变成 `<br>`）。
- **换行与 `<br>`**：
  - 编辑器里换行会**自动生成 `<br>`**，你平时看不见也不用管它。
  - 想看换行在哪：右侧「**文案内容**」输入框下方有「**显示 `<br>` 换行标记**」开关 ——
    开启后画布的就地编辑框里会用**淡灰色**标出 `<br>`。这只是显示，不影响内容，删除换行也不会出问题。
- **编辑框里的预览与画布一致**：字号、粗细、斜体、颜色、下划线、删除线都会在编辑框里如实显示。
- 在编辑框里**选中一段文字**后**右键**，可以只给这一小段加粗 / 改色 / 改字号 / 下划线等（见 3.6）。

### 3.4 缩放与画布宽度

- `Ctrl` + 滚轮：缩放画布（0.5x ~ 2x）。
- 工具栏「缩放」按钮显示当前比例，旁边有归位按钮（一键回到 100%）。
- 拖动画布左右边缘的手柄：调整画布宽度（拖哪边、锚定另一边）。
- 设备切换：**自适应（铺满窗口）/ 电脑（1920px）/ 平板（768px）/ 手机（375px）**；
  工具栏「设备」组和属性面板顶部的设备切换条都能用，两处状态实时同步。

### 3.5 Alt 增强交互（重要）

**按住 `Alt`**，画布元素才进入"可直接编辑"状态（平时只负责选中/预览，避免误触）：

| 操作 | 效果 |
|---|---|
| `Alt` + 指针贴到元素**边缘**，拖动 | 快捷**调整大小**（改宽/高） |
| `Alt` + 指针落在**文字元素**中间，左右拖动 | 快捷**改字号**（左变小 / 右变大，拖动时鼠标隐藏） |
| `Alt` + 指针落在**其它元素**中间，拖动 | 快捷**移动位置**（定位元素改 left/top，常规流元素改 margin） |
| `Alt` + 单击（不拖） | 选中父级（老行为不变） |

细节：

- 悬停时会有**虚线高亮框**和对应光标（左右拉伸 / 上下拉伸 / 两种对角 / 移动 / 手型），一眼看出能干什么。
- 拖动时屏幕上有**实时数值气泡**（尺寸 / 字号 / 位移）。
- 一次拖动 = **一条撤销**：松开后按一次 `Ctrl + Z` 就整体回到拖动前，**不会"慢慢变小/变大"**。
- **只有行内元素（`span`/`strong`/`a` 等）不参与贴边改大小** —— 它们没有块级盒子，贴边拖动没有意义；行内文字走"左右拖改字号"。
- **缩放的方向**：贴哪条边就改哪条边；贴左 / 上边时元素会同时"挪回去"，所以对侧边保持不动（不会出现"往反方向长"）。
- **移动有"墙"**：
  - **`fixed` 是独立的"视口层"**：只受**画布四边**（= 模拟浏览器视口）限制，**不再和文档流兄弟元素碰撞**；
    拖到视口底边 / 右边松手，会自动写成 `bottom: 0` / `right: 0`（而不是一个 `top: Npx` 的绝对值）；
  - **常规流元素**（普通的 div / 标题 / 段落）：**上方兄弟**是上墙（墙正好画在兄弟那条边上，
    还算上兄弟自己的外边距）—— 往上拖**不会压盖兄弟元素**，也**不会把外边距拖成负数**；
    下拖仍然可以撑长画布（**父容器设了固定高度**时会被挡在父容器内，四面都是墙）；
  - **`relative` 定位也按文档流处理**：最多回到自己的原位，不会往上压到兄弟元素身上；
    贴右 / 贴底时改用 `right / bottom` 锚定；拖到父容器**水平中线**时自动改成 `margin-left/right: auto`；
  - 定位元素（absolute）：横向不出父容器，还会和**邻近兄弟**碰撞 —— 墙就画在对方那条边上；
  - 墙的位置取父容器的**内边距内侧**，并且**把你自己的外边距也算进去**；
  - **拖动时边界线会一直显示**（橙色细线：内边距 / 外边距 / 兄弟元素的边），
    撞到时再叠一层更亮的闪 —— 这是**正常的限制**，不是 BUG。
- **画布会自动变长**：按住 Alt 往下拖时，画布临时向下延伸（想拖多远都行），**松手立刻恢复原长度**。
- **按住 Alt 时"已选中"的橙框会隐藏**：这时你看到的是 Alt 悬停框 / 拖动框 / 盒模型，不会两个橙框打架。
- **Alt + 滚轮**：不拖动时是**以鼠标为锚点的精准缩放**；正在拖动元素时改成**上下滚动画布**。
- **盒模型实时可视化（像浏览器 F12）**：按住 Alt 拖动时，被拖元素上会叠出四层半透明盒子 ——
  **外边距（橙）/ 边框（黄）/ 内边距（绿）/ 内容（蓝）**，每边的数值直接标在对应色带上；
  盒子中央显示**当前定位方式**（常规流 / 相对定位 / 绝对定位 / 固定定位）和实际尺寸。
  如果元素是 `relative`，还会从它的**文档流原位**画一条**红色虚线箭头**到当前位置，标出 `left / top` 偏移量。
- **「拖到墙外改父子关系」已暂时关闭**：这个交互太容易误触（稍微多拖一点就换了层级），
  现在**拖到墙边就停住**；要调整层级，请用**复制 / 剪切 + 粘贴到目标元素**（更精确、可预期）。
- **吸附对齐（像 PowerPoint）**：移动时如果元素的**左/中/右、上/中/下**靠近父容器或其它元素的对应位置（6px 内），
  会自动吸附并画出一条**粉红色参考线**，强迫症友好。
- **同选择器说明**：如果这个元素用了类名，改它的样式会同步给**所有用同一个类的元素**（这就是"类 = 一种样子"的设计）。

### 3.6 右键文字菜单（不用按 Alt）

适合"像 Word 那样给某段文字单独加粗/改色"的场景。菜单有两档，**规则统一、永远不会串色**：

**A. 整段文字**：直接**右键**一个**文字元素**（块级容器不弹此菜单）；或在编辑态里**选中了整段文本**。
- 改的是**整个元素**的 CSS —— 和右侧「CSS 样式属性」是**同一份数据，完全互通**（在哪边改都一样）。

**B. 只改选中的一小段**：双击文字进入编辑 → **只选中一部分文字** → **右键**。
- 只给选中的那几个字套样式，导出成 `<span style="…">选中的字</span>`（**内联样式，不用选择器**）。
- 因为是内联，它的优先级**高于整段 CSS**，所以整段的样式不会覆盖它 —— 两者各管各的，不会打架。

菜单里可调整：

- **字号**：`−` / `＋` 逐像素微调（可连续点）。
- **字重**：常规 / 中黑 / 加粗 / 特粗。
- **样式**：下划线 / 删除线 / 斜体（下划线与删除线可同时开）。
- **颜色**：12 个常用色一键切换，或点最右的 `＋` 开系统调色盘自定义。

> 菜单里显示的就是**这段文字当前的样式值**。
> 面板**点别处即关闭**、改动**实时生效**（没有"完成"按钮）；改错了按 `Ctrl + Z` 撤销。
> 为什么不支持渐变和字体？—— 这个菜单只服务"加粗某段文字"这类一次性微调；要完整控制请用右侧属性面板。

## 4. 属性面板

选中元素后，右侧「属性」页签从上到下依次是：

### 4.1 选择器与标识

- **类名 Class**：给元素起一个类名，同类的元素共享样式（"改一个全改"）。
- **ID**：唯一标识。
- **关系选择器**：如 `.card > h3`、`.hero > p:first-of-type`。点「自动推导」按元素在父容器里的位置生成最干净的选择器。
- **批量类名 / 批量关系选择器**：多选时一次性给多个元素设置。

### 4.2 CSS 样式属性

- 显示当前元素生效的所有 CSS 属性，按需增删。
- 点「＋ 添加属性」从完整 schema 里挑；不需要的行点 `×` 删除。
- 有"人话解释"和 `?` 帮助卡。

**中键搜索属性（强烈推荐）**：在**画布上对某个元素按鼠标中键** → 弹出一个小搜索框 → 敲属性名 → `Enter`：
- 右侧会自动切到「属性」、展开「CSS 样式属性」、**定位到匹配度最高的那一行并橙色闪烁**。
- 支持**拼错**、**只敲前几个字母**、**拼音缩写**（比如敲 `fontsizee`、`fsc` 都能找到 `font-size`）。
- 结果列表**分两态**，一眼就知道该不该按回车：
  - **蓝色 + 「已添加」** = 这个属性**已经加到这个元素上了**（有值）→ `Enter` **直接定位**。
  - **白色 + 「未添加」** = 还没加过 → 直接 `Enter` 只会提示"还没有添加"，**不会偷偷帮你加**。
- 想"加上再定位"：按住 **`Ctrl` 再按 `Enter`**（权重第一项恰好未添加时，框里会直接给出这条小字提示）。
- 关闭方式：`Esc`、或**点别处**（都会带退场动画）。
- 一句话：**中键 + 键盘，一步直达**，不用在长长的属性列表里翻。

**「＋ 添加属性」里的搜索也升级了**：
- 输入即按**匹配度排序**（精确 > 前缀 > 包含 > 别名 > 类别）。
- 还能**按属性值搜索**：比如输入 `flex`，会出现**蓝色条目**显示「显示模式 = flex」，
  点一下**同时写入属性名和属性值**，不用先加属性再选值。
- 搜不到时会明确显示「**没有匹配**」，不会列一堆无关属性。

### 4.3 盒模型与数值输入

- **外边距 margin / 内边距 padding / 边框宽度 border-width / 圆角 border-radius**：都用**4 个独立数值框**（上右下左），不要求手写简写。
- 数值框只填数字，单位用后缀或下拉；`auto` / `%` / `calc()` 可直接写。
- **滚轮调值**：点一下数值框进入输入态，滚动滚轮即增减（上滚增大 / 下滚减小），按住 `Shift` 一次调 10；停手自动提交，**一次聚焦 = 一条撤销**。
- **接设计变量（var）**：数值框右侧有一个 **`var` 按钮**，点开是变量菜单（色块 + 名字 + 当前值）——
  选中后这一项不再写死数字，而是写成 `var(--bc-xxx)`；之后在「变量」页签改一次值，**所有引用处一起变**。
  当前值已经是变量的输入框会**高亮**显示；还没定义过变量时，菜单里会给出引导。

### 4.4 颜色与渐变

- 「背景颜色」用统一控件，支持**纯色 ↔ 渐变**双模式。
- **渐变编辑器**（PowerPoint 风格）：
  - 顶部实时预览条；类型选**线性 / 径向**。
  - 线性：**角度方向盘**可拖拽 + 8 个快捷角度 + 「反向」。
  - 径向：**形状**（圆 / 椭圆）、**扩散范围**（最远角 / 最远边 / 最近边 / 最近角）、**中心位置**（居中 / 四边 / 四角）。
  - **色标**：每个色标一张卡片（上行颜色、下行位置）。**按住左侧 `⠿` 握把**可上下拖动调整顺序；**「位置」滑块**调整百分比。
  - **预制配色**共 6 组：暖色系 / 冷色系 / 自然系 / 高级感 / **径向扩散** / **多色标**（含 3~5 色标的彩虹、金属拉丝等）。
- 文字渐变：勾选后自动补齐"三件套"（`background-image` + `background-clip:text` + `-webkit-text-fill-color:transparent`）。

> ⚠ 拖动色标请抓 **`⠿` 握把**；色标卡片上的「位置」滑块是专门用来调百分比的，不会被误当成拖拽。

### 4.5 字体

- **字体库**：全屏面板枚举本机全部字体 + 常见字体目录（按公开资料预标注「可商用 / 商用需注意」），左侧实时预览。
- 支持**多字体回退链**拖拽排序，可登记 `@font-face` 自定义字体。
- 另有字号、字重、行高、字距、对齐、文字颜色、文字阴影等独立控件。

### 4.6 边框 / 阴影 / 变换 / 过渡 / 透明度

- **边框**：四边粗细、线型、颜色分别可调并实时预览。
- **盒子阴影**：支持多层与内阴影，带滑块与预设。
- **文字阴影**：同上。
- **变换 transform**：位移 / 缩放 / 旋转，带滑块与预设。
- **过渡 transition**：由「交互状态」区域统一管理。
- **透明度 opacity**、**行高 line-height**：滑块 + 数值。

### 4.7 快捷助手

把"多条 CSS 属性配合才能做出的效果"打包成一句话：

- Flex 布局 / Grid 布局 / 文字渐变。
- 每个块都有 `?` 帮助卡（原理 + 用法）。
- 生成的属性可一键从下方 CSS 列表隐藏（全局开关在「设置 → 编辑器与画布」）。

### 4.8 交互状态（伪类）与动效

- 支持 `:hover` / `:active` / `:focus` / `:link`。
- 每个伪类内置 **≥4 个预制动效**（上浮 / 放大 / 发光 / 下沉 / 外圈光晕…），点击即套用。
- 套用后可用**滑块微调**：位移 / 缩放 / 旋转 / 阴影 / 过渡时长 / 圆角（拖动瞬态，松手入栈）。

### 4.9 响应式覆盖（电脑 / 平板 / 手机）

- 属性面板顶部是**三个设备分段 + 右侧一枚小的「自适应」按钮**：
  - 点「电脑 / 平板 / 手机」= 把画布切成对应宽度（1920 / 768 / 375px），同时切到该断点编辑；
  - 点小按钮 = **画布铺满编辑区（自适应）**。这个按钮**不会常亮**：设备高亮始终按**画布实际宽度**判断
    （自适应时窗口变窄，会自动高亮平板 / 手机），不会出现"自适应亮着、却不知道在改哪个断点"。
- 与工具栏「设备」组是同一套状态，**在哪切都行、两处实时同步**。
- 在非电脑断点下改的属性，只作为该断点的**覆盖**（有标记点提示）。
- 「清空当前设备覆盖」一键还原继承电脑端。
- **整页自动适配**：一键扫描全页并给出调整建议（固定宽度→100%、多列→单列…），确认后一次性写入，一条 `Ctrl+Z` 整体撤销。

### 4.10 设计变量（Token）

- 把主色 / 圆角 / 间距 / 字号 / 阴影定义成 `--bc-*` 变量。
- 元素样式里引用 `var(--bc-primary)`，**改一处全站跟着变**。
- **变量严格跟着工程走**：新工程**不再预载**一套默认变量（以前每个新工程都带同样的 15 个，
  看起来像"项目之间共享"）；需要现成的一套时，点「默认集」一键载入。
- **添加方式和元素 / 全局样式一致**：点「**添加属性**」打开同一个 CSS 属性菜单（分类 + 中文 / CSS 名 / 拼音搜索），
  选一个属性就自动建一个对应类型的变量（颜色 → 颜色组、圆角 → 圆角组、字号 → 文字组…），
  名字自动从属性名生成（如 `letter-spacing`）并直接进入改名状态；**不适用的属性会标「不生效」并禁用**。
- 「模板」按钮仍保留一板预设（主色 / 圆角 / 间距 / 字号 / 阴影），点一下就建好。
- **分组可折叠**：颜色 / 圆角 / 间距 / 文字 / 阴影…每组都能收起，变量多的时候面板不乱；
  折叠状态跟着工程文件一起保存。
- 导出时写入 `:root`，脱离本软件同样生效。

### 4.11 页面页签（整页设置）

属性面板顶部的「页面」页签管的是**整页**（写进一条 `body` 规则，画布和导出都生效），分两块，都能折叠（状态跟工程保存）：

- **body 设置**：常用项的**专属卡片** —— 页面背景色 / 文字颜色 / 链接颜色（点色块开调色盘）、
  页面字体、正文字号、行高（数字框 + 单位下拉）、标题颜色；
  以及两个开关（**去掉浏览器默认 8px 白边**、**重置标题/段落默认间距**）。
- **全局样式**：body 设置没覆盖到的属性在这里添加。点「**添加属性**」打开的是**和元素 CSS 面板同一个菜单**：
  按类别分组、支持中文名 / CSS 名 / 拼音搜索；加进来的每个属性同样渲染成**专属卡片**
  （颜色有调色盘、数值有数字框 + 单位、`padding` / `margin` 是四向输入、枚举是下拉），
  不再是一排"属性名 + 值"的裸文本框。留空的值不会输出，点行尾的删除按钮移除该属性。
- **添加属性菜单不会跑出屏幕**：按钮贴近面板底部时，菜单会自动**向上展开**，并把整块菜单滚到可见位置。
- 老工程如果之前用「高级 CSS」写过全局样式，内容**仍然生效**；面板里会给出提示条，可一键清空（此入口不再新增）。

## 6. 表格编辑器

选中一张 `<table>` 后，一键进入**独立表格编辑页**。设计原则：**能用鼠标拖的绝不做按钮墙**。

### 6.1 插入行 / 列

- 鼠标移到行与行、列与列之间的缝隙 → 浮出插入轨道和 `＋`（整条轨道都是热区）。
- **点一下**：插 1 行 / 1 列。
- **按住拖动**：一次插 N 个（实时高亮 + 计数气泡，`Esc` 取消）。

### 6.2 选中与合并

- 格子上**按住拖动** → 框选矩形区域。
- `Ctrl` / `⌘` + 点 → 加选（选区始终是矩形，取并集）。
- `Shift` + 点 → 从选区左上角拉伸到你点的那一格。
- 点行号 / 列号 → 选中整行 / 整列。
- `Ctrl + A` → **全选整张表**（所有单元格）。
- 顶部选区操作条：合并 / 拆分 / 设为表头 / 删行 / 删列。

### 6.3 编辑内容

- **双击格子**就地改文字（`Enter` 确认 / `Esc` 取消）。
- `Del` / `Backspace`：只清空格子文字，不动结构。
- `Ctrl + C`：复制选区（Tab 分隔，可直接粘进 Excel / WPS）。
- `Ctrl + Shift + C`：复制整张表的 HTML 源码。

### 6.4 右侧面板（所见即所得）

三个清晰区块，改任何一项**左边表格与右侧预览同时实时变**：

1. **选择器与标识**：表名 + 一键自动命名 + 体检开关。
2. **单元格设置**：选中格/多格；顶部是实时预览，下面按**颜色 / 数值 / 文本**分小节；底部「应用到全部单元格」。
3. **表格设置**：整表样式（`border-collapse` / `table-layout` / `border-spacing` / `caption-side` / 垂直对齐…）+ 效果预览。
4. **一键预设样式**：每套预设画一张缩略小表。

要点：

- **「自动取名」保证每个内部元素都拿到只属于它自己的选择器**：多张表重名会自动改用 `-2` / `-3` 后缀，不会出现"两张表选择器一样、改一张另一张跟着变"。
- 数值输入统一「数字 + 单位」（点输入框滚轮可调，`Shift` 一次调 10）。
- 所有连续操作**合并成一条撤销记录**。
- `Esc` 或点结构网格空白处取消选中。

## 7. 导出与预览（含导出前体检）

- **预览**：在默认浏览器打开当前页面（临时文件）。
- **导出 HTML**：保存为单个干净的 `.html` 文件。
- **导出前体检**：导出/预览前自动扫描并拦截严重问题（写了 `:hover` 却没类名、ID 重复、同名样式不统一…），按严重度列出并支持**一键修复**。
  - **表格默认不参与体检**（一格一个 `td/th`，正常做表格既不起类名也不写 CSS，参与只会刷屏"未命名元素"）；需要时在表格编辑器右侧面板打开「让这张表参与导出前体检」。
  - 向导头部会写明"已跳过 N 张表格"。
- 导出代码原则：**类名 / 关系选择器优先**，无名元素走行内样式并提示起名；伪类样式必须有类名/ID/关系选择器才能导出后生效。

## 8. 项目与多标签

- **保存 / 打开**：`.bcproj` 自定义格式（本质是 JSON）。
- **多标签**：像浏览器一样同时开多个页面，会话自动恢复，撤销栈按标签各自独立。
- **工程库**（工具栏「全部项目」/ 菜单）：集中查看 `data/projects/` 里的所有工程。
- 关闭保护见 1.1。

### 8.1 删除工程（三步安全防护）

工程卡片右下角的 🗑️ 会打开**三步安全防护**流程，防止手滑删错：

1. **第 1 关 · 手打项目全名**：必须**手动完整输入**项目名称，`下一步` 才会亮。
   （**不支持**点名字自动填充 —— 这一关的意义就是让你"亲手打一遍"。）
2. **第 2 关 · 滑块验证**：出现 **3 个滑块**，**方向与位置每次随机**；
   必须**按 1 → 2 → 3 的顺序**把它们拖到竖线标记处（没轮到的不给拖；到位会自动吸附并打勾）。
3. **第 3 关 · 最终确认**：再读一遍影响，点「我已确认，永久删除该项目」才真正删除。

规则：

- **点遮罩不会关闭流程** —— 想退出只能点**「取消」**（按钮特意做大了）。
- 删除会**连同该项目名下的所有历史快照 / 自动备份一起清理**，**无法从回收站恢复**。
- 流程本身带完整的进退场动画。

## 9. 更新中心与后台任务

### 9.1 更新中心

- 读取与下载都做**三级镜像自动回退**（NexaCode → gh-proxy(v4) → GitHub 直连），全程无感。
- 页面按三个板块组织：
  - 「**可更新**」默认展开，发行说明直接显示（Markdown 渲染）。
  - 「**可选择更新（重装）**」与「**历史版本**」默认折叠。
  - 历史版本可逐条看发行说明、「**下载 zip**」到 `data/downloads/`，底部「查看更多」继续往前翻。
- 读取源/下载源收进默认折叠的「检测详情」。

### 9.2 后台任务（工具栏「任务」按钮）

- 所有下载 / 更新都是**主进程里的后台任务**：可**暂停（保留断点）/ 继续（HTTP Range 续传）/ 取消**。
- 任务记录写进 `data/tasks.json`，**离开更新页、切视图、甚至重启软件都还在**。
- 工具栏「⋯ 更多」左边的「**任务**」按钮：鼠标浮上去展开任务面板（当前任务、进度、已下载 MB、走的哪个镜像），可直接 停止 / 继续 / 取消 / **打开 zip 所在文件夹** / 移除。
- 「下载 zip」只落盘、不替换程序 → **不弹全屏遮罩、不锁编辑器**，进度条贴在对应版本卡片正下方，完成后按钮直接**打开这个 zip 所在的文件夹**。
- 只有**真正的更新**（替换程序本体）才弹全屏遮罩并锁死编辑器，替换时永远排除 `data/`。更新**不再有二次确认弹窗**，下载阶段也不锁编辑器 —— 只有到「解压 / 替换 / 重启」那一步才盖遮罩。
- 更新完成后会自动把**程序文件夹改名带上新版本号**（如 `BlockCanvas-v0.4.4`，必要时弹一次系统 UAC 授权框）。

- **搜索**：顶部搜索框输入即搜，弹出**按权重排序**的结果列表，点结果**自动切到对应文档并跳到具体段落**；全文同时高亮命中词。
- **文档内的超链接可以直接点**：三份文档之间互相跳转；文内目录的 `#锚点` 也能平滑滚到对应章节。
- 左侧自动生成目录，滚动时高亮当前章节；开/关有过渡动画。

## 12. 扩展系统（插件 / 资源包）

扩展统一放在程序目录 `extensions/` 下：

```
extensions/
├─ plugins/<id>/        # 插件（manifest.json + 执行代码 index.js）
└─ resources/<id>/      # 资源包（manifest.json + templates/*.json）
```

- **插件 API**：入口 `index.js` 由 `new Function('Bc', source)(Bc)` 求值，宿主对象提供 `registerCss / registerCommand / registerElement / registerProperty / registerExportHook`。
- 插件注册的**工具栏按钮只能进「⋯ 更多」**；要放主区/右区，用「设置 → 工具栏管理」里的「＋ 插入按钮」。
- 在「设置 → 扩展与插件中心」可导入 / 导出 / 启停扩展。
- 详细规范见 [扩展规范](扩展规范.md)。

## 14. 数据、备份与便携

- **纯便携设计**：所有数据都在程序目录 `data/` 下，**不写系统 AppData 和注册表**。
- 目录结构：

```
data/
├─ projects/     # 工程文件（.bcproj，ZIP 容器）
├─ backups/      # 自动备份历史快照（按项目隔离）
├─ session/      # 会话草稿（未保存的标签）
├─ tmp/          # 程序自己的临时区（预览页 / Chromium 运行时临时文件）
│  ├─ preview/   #   浏览器预览页（只保留最近 5 个）
│  └─ system/    #   Chromium 内核的运行时临时目录
├─ config.json   # 用户配置
├─ downloads/    # 「下载 zip」落盘位置
├─ tasks.json    # 后台任务记录
├─ user-data/    # Chromium 隔离区
└─ extensions/   # 运行时扩展副本
```

- **工程文件是 ZIP 容器**：`.bcproj` 本质是个 zip（和 `.docx` / `.xlsx` 一个套路），
  把后缀改成 `.zip` 就能用任意解压软件打开 —— 里面有 `manifest.json`（名称 / 版本 / 元素数）+ `scene.json`（场景）。
  换句话说：**工程既能被软件打开，也能被你自己看、被别的工具处理**。
- **老工程会自动升级**：老版本存的纯 JSON 工程，启动后软件会**在后台静默换成新格式**，
  并留下一份 `.v1.bak` 备份（万一有事可以自己还原）。这一步是幂等的，不用你做任何操作。

- **自动备份**：按设定周期自动快照（按项目名称隔离），可设置保留数量。
- **崩溃恢复**：异常退出后可从自动快照恢复。
- 更新时**只替换程序本体**（排除 `data/`），删掉 `data/` 程序也能自己重建。
- 菜单「设置 → 打开便携数据文件夹」可直接定位到 `data/`。

### 14.1 存储与缓存怎么管（设置 → 存储与自动备份）

「存储占用明细」把占用拆成 **8 类，互斥且可加和**（加起来正好等于总占用，不会"对不上账"）：

| 分类 | 能一键清理吗 | 说明 |
|---|---|---|
| **Chromium 运行缓存** | ✅ 可清 | 渲染 / 脚本编译 / GPU 的临时文件 |
| **临时文件（预览 / 更新 / 系统 Temp）** | ✅ 可清 | `data/tmp` 里的预览页与内核临时文件，外加**旧版本**留在系统 Temp 里的遗留 |
| **更新包下载** | ✅ 可清 | 手动下载的更新 zip（会保留最近一次） |
| **界面偏好与会话** | ❌ 保留 | 窗口布局、面板宽度、未保存草稿 —— 清掉会"设置被重置" |
| **项目工程文件 (.bcproj)** | ❌ 保留 | 你的作品本体 |
| **历史快照与备份** | ❌ 保留 | 可单独用"清理孤立快照"回收已删项目的部分 |
| **扩展与插件包** | ❌ 保留 | 插件 / 资源包 |
| **其它** | ❌ 保留 | `config.json` / `session.json` / `tasks.json` 等 |

- 每一行右边都有对应的**「清理」按钮**（只有"可清"的三类才有）；顶部还有**「一键立即清理」**清全部可清项。
- 底部**合计行**同时显示 `data/ 目录` + `系统 Temp 遗留` = 合计（`data/tmp` 已算在 `data/ 目录` 里，不重复计）。
- **缓存都在哪？** 一句话：**程序自己的临时文件全在 `data/tmp/`**（浏览器预览页 + Chromium 内核的运行时临时文件），
  系统 Temp 里只会有**更新替换脚本**（它必须在程序目录之外执行），而且脚本**跑完会把自己所在的整个目录删掉**。
- **预算兜底（防止某一个目录悄悄长大）**：
  - `data/downloads/`：**永远保留最近一次下载**，其余超过 30 天或总量超过 512 MB 时从最旧的开始淘汰；
  - `data/tmp/preview/`：只保留最近 5 个预览页；
  - `data/tmp/` 整体：256 MB 上限（**不碰 `tmp/system`** —— 那是内核正在用的）；
  - `data/backups/<项目>/`：每个项目最多 15 份快照、总量 200 MB。
- 三个启动开关：
  - **启动时自动清理临时文件**（默认**开**）—— 每次启动回收 `data/tmp` 与程序留在系统 Temp 里的文件；
  - **启动时自动清理临时缓存**（默认关）；
  - **启动时自动清理孤立残留快照**（默认开）。
- **清理报的数字 = 界面上真正减少的数字**（用清理前后实测差值计算，不是"我删了几个文件"）。
- **红线**：清理**绝不会**碰你的项目、快照、扩展，也不会碰界面偏好与会话。

## 15. 常见问题 FAQ

**Q：更新后我的工程还在吗？**
在。更新只替换程序本体，`data/` 里的工程、快照、配置全部保留。

**Q：系统临时目录里为什么会有 BlockCanvas 的文件？**
浏览器预览要交给系统浏览器打开、更新脚本要在主程序退出后独立执行，所以必须落盘。
程序**启动时会自动回收**这些文件（开关默认开），也可以在「设置 → 存储」里点「临时文件」那行的「清理」立刻回收。

**Q：清缓存会把我的设置清掉吗？**
不会。缓存和"界面偏好与会话"是**两个分类**，清理只作用于前者。

**Q：为什么我改了某个元素，和它同类的元素也跟着变了？**
它们用了**同一个类名**（"类 = 一种样子"）。想让改动只作用于一个元素，请用右键文字菜单的**内联样式**，或给它单独改类名。

**Q：色标拖不动 / 位置滑块拖不了？**
拖色标顺序要抓左侧的 **`⠿` 握把**；卡片上的「位置」滑块是调百分比的，两者已分开，互不干扰。

**Q：按住 Alt 后画布上的元素出现虚线框是什么？**
那是"可直接编辑"的提示。贴边拖 = 改大小，文字中间拖 = 改字号，其它中间拖 = 移动。不按 Alt 时一切照旧（只选中/预览）。

**Q：框选不到画布下面的元素？**
把鼠标移到画布区的上/下边缘，画布会自动滚动，滚出去的部分也能被框进来。

**Q：下载/更新到一半想退出？**
没关系。下载是**后台任务**，记录在 `data/tasks.json`，下次打开软件在「任务」按钮里点「继续」即可断点续传。

**Q：预览/导出被拦住了？**
那是「导出前体检」拦下的严重问题（如写了 `:hover` 却没类名）。按向导提示一键修复即可。

**Q：网络连不上更新？**
更新走三级镜像自动回退。若全部失败，请关闭 Watt Toolkit / Clash 等后台代理后重试。
