## 已修（v0.4.5）

- [x] **独立弹窗的任务栏图标是 Electron 默认图标**
  - 现象：主窗口图标是三色 Logo，但其他窗口 / 原生保存-打开对话框在任务栏显示 Electron 原子图标。
  - 原因：主进程只给主窗口设了 `icon`；Windows 还会按 `AppUserModelId` 归组，未设置时回落到 `electron.exe` 的图标。
  - 修法：`appIconPath()` 统一取图标；`app.on('browser-window-created')` 给每个新窗口补图标；
    `app.setAppUserModelId('com.blockcanvas.app')` 在 `whenReady` 里先设；所有 `dialog.show*` 走包装函数挂到主窗口。
  - 遗留：开发态下 `electron.exe` 宿主进程的原生对话框仍显示原子图标，**打包后正常**。

- [x] 首页渐变色标卡片"前面一大片空白"（`align-items:center` 与两行布局冲突）
- [x] 外轮廓预览线画到卡片外面（`outline` 天生在盒外）
- [x] 属性名前的"子"字小方块（视觉噪音）
- [x] 元素面板 7 列各自滚动条（改整块单滚动）
- [x] 图层树文字预览压住操作按钮
- [x] 添加属性菜单顶出窗口底部（CSS 限高与 JS 测算值不一致）
- [x] 标签栏技巧条像输入框
- [x] 白色色块在白底上隐形

## 待办（按建议顺序）

### 1. 工程容器与素材（数据层，改动大，单独一轮）

- [ ] **素材库**：`.bcproj` 里已预留 `assets/`，但保存时没有把引用的本地图片/视频真正打包进去，
      换机器打开会丢图。需要：保存时收集 `bc-img://` 引用 → 写入 `assets/` → 场景里改写成容器内相对路径。
- [ ] **图库面板**：把已导入素材做成可复用的缩略图网格（拖到画布即用）。
- [ ] **视频 / 音频元素**：现在只有 `video` 元素类型，缺音频；需要播放器属性卡（controls / 循环 / 自动播放 / 封面）。

### 2. 工程管理

- [ ] **外部工程登记**：`project:list` 只扫 `data/projects/`，用户从别处导入的工程不在列表里。
      需要一份 `registry.json` 记录外部路径，并在文件被移动/删除时标灰。
- [ ] **损坏工程处理**：ZIP 读不出来时目前只报"不是有效的工程文件"，应给出"尝试修复 / 从快照恢复 / 仅提取场景"三个出口。
- [ ] **多页工程**：`SCHEMA_VERSION = 2` 只有单页 `scene.json`；多页需要 `pages/` + 路由表 + 导出时的多 HTML。
- [ ] **路径基准**：`bc-img://` 目前按绝对路径解析，工程换目录就失效（与素材库一起解决）。

### 3. 更新器

- [ ] 更新窗口单实例（重复点"检查更新"不要开多个窗口）。
- [ ] 更新日志落盘（`data/logs/update-*.log`），失败时能让用户把日志发过来。
- [ ] 更新前确认没有未保存标签（现在只在遮罩层拦鼠标，快捷键仍可能触发）。
- [ ] 跨平台：macOS / Linux 的分支还没有实际验证过。

### 4. 深色模式

- [ ] 现在是全局 CSS 变量切换 + 一批 `is-dark` 覆盖，散在 5 个文件里。
      计划改成插件化（`extensions/theme-dark/`），由插件注入变量表，主程序不再写死深色规则。
      —— 属于架构调整，不要和 UI 修补混在一个版本里做。

### 5. 打包与分发（用户明确要求暂缓）

- [ ] Windows 一键安装程序（向导式）
- [ ] Windows / macOS / Linux 三端安装脚本
