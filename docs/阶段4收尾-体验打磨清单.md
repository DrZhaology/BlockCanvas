# 阶段 4 收尾 · 体验打磨清单（面向 v0.4.3 → 阶段 5 的过渡）

> 用途：阶段 4（响应式与打磨）已接近尾声，功能面基本齐了。这份清单回答一个问题：
> **"在进入阶段 5 之前，还有哪些体验上的打磨值得做？"**
> 排序原则：**先解决"用起来别扭 / 会踩坑"，再补"更顺手"，最后才是"锦上添花"。**
> 每条都标了「为什么」「大概怎么做」「工作量」。
> 工作量口径：🟢 半天内 / 🟡 1~2 天 / 🔴 3 天以上。

---

## 一、高优先级（直接影响日常使用，建议 0.4.3 收尾就做）

### 1. 交互「可发现性」：Alt 手势没人知道 🟡
- 现状：Alt 贴边缩放 / 按住移动 / 按住文字改字号 都很好用，但**只写在 tooltip 和快捷键表里**，普通用户基本不会发现。
- 建议：
  - 首次进入画布时，右下角给一条**一次性**手势提示（"按住 Alt 试试拖动元素"），点掉后不再出现（走 `bc-flag:` 持久化）。
  - 选中元素且**没按 Alt** 时，在选中框角上放一个极淡的"手柄暗示"（hover 才显形），提示"这里可以拖"。
- 收益高、风险低，是当前**性价比最高**的一条。

### 2. 连续操作的「撤销粒度」统一审计 ✅ 已完成（v0.4.4g）
- 现状：画布 Alt 拖动、颜色拖动已经是"一条撤销"；但**其它滑块/滚轮/连续输入**未必都做了 `beginStyleEdit/endStyleEdit`。
- 已做：逐个核对连续控件（滑块 / 滚轮 / 拖拽）都走 `beginStyleEdit → 瞬态 → endStyleEdit`，
  并确认 `updatePseudoStyle` 也尊重编辑会话；新增 `probe-undo-granular.mjs` 守住这条。
- **体验方法（你自己试）**：
  1. 选中一个元素 → 属性面板加「不透明度」→ **按住滑块拖一大段** → 松手 → 按一次 `Ctrl+Z`：
     应该**整体回到拖动前**，而不是一格一格往回退。
  2. 点一下「宽度」数值框 → **滚轮连滚好几下** → 点空白处 → 按一次 `Ctrl+Z`：同样应整体还原。
  3. 顺带试：颜色调色盘拖动、阴影滑块、`:hover` 动效滑块、渐变角度盘 —— 都应"一次拖 = 一次撤销"。
- 这是"以前颜色的教训"的**系统性收尾**，不做就会零散复发。

### 3. 画布元素也要有「右键菜单」 ⏸ 暂缓（用户 2026-10-11 决定先不做）
- 现状：只有文字元素有右键菜单；容器/图片/按钮没有。
- 建议：给所有元素统一一个右键菜单：**复制 / 删除 / 复制样式 / 粘贴样式 / 上移一层 / 下移一层 / 锁定 / 隐藏 / 添加类名**。
- 用户反馈：格式刷（复制样式）场景较少，**本轮先不做**。

### 4. 「复制样式 / 粘贴样式」（格式刷）⏸ 暂缓（同上）
- 现状：想复用一套样式只能靠类名，零基础用户不会。
- 建议：右键菜单加"复制样式"，再在别的元素上"粘贴样式"（可跨元素）。这是最像"Word"的能力，普通人一学就会。
- 用户反馈：**暂不做**。

### 5. 对齐辅助线 / 吸附（Alt 移动时）✅ 已完成（v0.4.4g）
- 现状：Alt 拖动是"自由像素"，没有对齐参考，做整齐排版全靠眼力。
- 已做：参考线 = 父容器 + 所有兄弟的**左/中/右、上/中/下**；元素这三条边靠近 6px 内自动**吸附**，
  并画出**粉红细参考线**（PowerPoint 风格）。
- 与已有的"墙"配合，手感专业了一个档次。

### 6. 属性面板「搜索」✅ 已完成（v0.4.4g，v0.4.4h 补两态）
- 已做四件事：
  1. **中键搜索**：画布上对元素按鼠标中键 → 敲属性名 → Enter → 右侧展开 CSS 属性并**橙色高亮定位**；
     支持拼错 / 前几个字母 / 拼音缩写。
  2. 结果**分两态**（v0.4.4h）：**蓝色「已添加」→ Enter 直接定位**；**白色「未添加」→ Enter 只提示、不偷偷加**，
     想加上再定位用 **`Ctrl + Enter`**；`Esc` / **点别处**都能关闭（带退场动画）。
  3. 「＋ 添加属性」搜索**按权重排序**，并支持**按属性值搜索**（蓝色条目「属性名 = 属性值」，点一下一起插入）。
  4. 搜不到时明确显示「没有匹配」。

### 6b. 画布「墙」的可读性 + 拖拽改父子关系 ✅ 已完成（v0.4.4h）
- 拖动时**常显橙色边界线**（内边距 / 外边距 / 兄弟元素的边），撞到时更亮地闪 —— 边界一眼可见。
- **撞墙后继续往外拖 → 快速改父子关系**：元素淡化、鼠标下块级元素高亮「放入此元素」、松开即放入。
  （这是"结构整理"最缺的一条快捷路径，不用去图层面板。）

### 6c. 破坏性操作的「安全防护」✅ 已完成（v0.4.4h）
- 删除工程从"两步"升级为**三步**：手动完整输入项目全名（**去掉点击自动填充**）→ **3 个随机方向/位置滑块按顺序拖到位** → 最终文字确认；
  点遮罩不关闭（只能点特意加大的「取消」），删除时一并清理该项目名下所有快照与备份，全流程带进退场动画。
- 顺带修掉：**选中元素后 `Ctrl+Z / Ctrl+Y` 失效**（根因是画布 `preventDefault` 让焦点留在属性输入框里，
  而全局快捷键对输入框一律 return）—— 现在撤销/重做判定提到输入框守卫之前，点画布也会主动 blur。

### 7. 撤销栈的**内存与性能**🔴
- 现状：`history` 存的是整棵 scene 的深拷贝。文档一大，撤销几十步会明显吃内存、切标签变卡。
- 建议：改成**结构化增量补丁**（或至少做"快照节流 + 上限"）。这是**长期隐患**，越晚做越痛。

## 二、中优先级（更顺手 / 更专业，阶段 4 尾巴或阶段 5 早期）

### 8. 画布上直接拖动排序 / 拖入容器 🟡
- 现状：调整层级/父子关系只能去"图层"面板拖。
- 建议：画布上拖拽元素时，显示"插入位置指示线"，松手即改变顺序/归属。

### 9. 多选对齐 / 分布工具 🟢
- 现状：多选只能整体移动。
- 建议：多选时出现"左对齐 / 水平居中 / 右对齐 / 顶对齐 / 垂直居中 / 等间距"一排按钮。

### 10. 断点预览（并排 / 快速切换）🟡
- 现状：切断点会整页变宽变窄，来回对比很烦。
- 建议：加一个"三断点并排预览"开关（只读缩略），或记住"切回来时的滚动位置"。

### 11. 表格的移动端友好 🟢
- 现状：宽表格在手机端会溢出。
- 建议：给表格一个"移动端横向滚动"选项（导出时包一层 `overflow-x:auto`）。

### 12. 导出增强 🟡
- 现状：只能导出单个 HTML。
- 建议：① "只导出选中元素"；② HTML/CSS 分离导出；③ 压缩选项；④ 导出时把本地图片**一起打包**（现在相对路径的图导出后会断）。

### 13. 富文本再进一步 🟢
- 现状：局部富文本只支持 字号/字重/颜色。
- 建议：补**斜体 / 下划线 / 链接 / 高亮**（同一套 `runs` 模型，加几个按钮即可）。

### 14. 空状态与示例工程 🟢
- 现状：新标签是空白的，新手不知道该干嘛。
- 建议：空画布给"从一个模板开始 / 插入标题试试"的引导卡片；或内置一个"示例工程"一键打开。

### 15. 元素面板 / 工具栏的"最近使用" 🟢
- 现状：常用元素每次都从头找。
- 建议：元素面板顶部加"最近用过"；工具栏同理。

## 三、低优先级（可延后到阶段 5 / 后续版本）

- **深浅主题的完整适配**：现在深色靠插件，部分新面板（画布就地编辑、右键菜单）还需逐个核对对比度。
- **国际化（i18n）**：如果面向非中文用户再考虑。
- **无障碍 / 纯键盘操作**：面板 Tab 焦点顺序、`aria-*`、焦点环——面向专业用户，但工作量不小。
- **画布标尺 / 网格 / 参考图**：偏专业设计向。
- **更新通道（稳定/预览）与回滚**：更新体系已可用，回滚是加分项。
- **插件市场 / API 文档站**：等插件生态有需求再说。
- **大文档虚拟化渲染**：等真有大文档案例再做（与第 7 条相关）。
