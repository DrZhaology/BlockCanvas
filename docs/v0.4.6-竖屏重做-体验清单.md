## 0. 怎么进竖屏

三种都行，效果完全一样（判据只有一条：窗口宽度 < 900px）：

1. 把窗口拖窄到 900px 以下；
2. 窗口拉高变窄（手机/竖屏平板就是这种）；
3. 浏览器里打开网页版再缩窗口。

判断成功的标志：**顶部整条消失**，屏幕最下面出现一条按钮栏（撤销 / 重做 / 方框数字 / 新建 / 三）。

## 一、这轮补的（之前确实没做 / 做错了）

### 1. Alt 模式的触摸体验（4 条，原来一条都没做）

| 你说的 | 现在怎么验 |
| --- | --- |
| 长按元素才能选中；不能多选；按住下一个，上一个自动取消 | 「更多 → Alt 模式」打开后，长按元素（420ms）选中；再长按另一个，选区只剩它 |
| 选中后中间出现一个 SVG（上下左右箭头），按住能改位置 | 元素正中出现蓝色圆钮（四向箭头），按住拖动 → 元素跟着走 |
| 4 个角出现方框，方框**外面一部分**也能按到（手指大） | 4 角各一个白色小方块（视觉 20px），实际命中区 **44×44** |
| 4 条边也能按住调整 | 4 条边中点各一条蓝色细条（视觉 6px 厚、命中 26px 厚） |

实现上**没有重写拖动逻辑**：手柄按下时把"拖谁 / 哪种模式 / 哪条边"交给桌面那套
`useAltDrag`（贴墙吸附、双边约束、松手归一化全部复用），所以手感与电脑端 Alt 一致。

顺带改了一条老规矩：以前「Alt 模式开着就关掉竖屏手势层」（怕抢事件），结果触摸屏上
元素既选不上也拖不动。现在手势层照常跑 —— 长按=单选、单指=平移、双指=缩放，
只有手柄那几块交给拖拽。

硬指标（新增 `probe-alt-touch.mjs`，18 项全过）：
长按单选 ✓、手柄 4 角 4 边齐全 ✓、框贴合元素 ±0✓、角手柄命中 44/视觉 20 ✓、
拖右下角 180→228（宽）/80→120（高）✓、拖中间移动柄 x 18→58 且不改宽度 ✓、
拖右边 228→268 且不改高度 ✓、取消选中/关掉 Alt 手柄消失 ✓。

### 2. 设置页「右侧进入 / 右侧退出」

原来是 `bcViewIn`（淡入 + 上移 8px），退出干脆没有 —— 就是你说的"单纯刷新一下"。
现在进出设置页都走 View Transitions 的两段动画：旧页往右滑出、新页从右滑入。
只对设置页挂（会话页那套"画布缩小成缩略图"是专门做的，不能被通用滑屏顶掉）。

### 3. 设置按形态分组（这条之前也没真做）

「电脑设置」在竖屏里现在**整组不显示**，「竖屏设置」在宽屏里也不显示。
原来竖屏列表里还挂着「工具栏管理」，那一页在 412px 下把说明文字压成了**一列单字**
（体检脚本抓到：`SPAN` 宽 4px、高 925px）—— 正是你说的"文字一行一个"。

### 4. 关闭页面的"脏"判定

用户原话：「新建了一个画布，但是什么都没有修改，直接点叉叉直接关闭，不要提示要不要保存。
但是这个页面添加过元素，但是全部删除了，不要直接能关闭，还是显示二级菜单。」
以前只看"画布上有没有元素"，所以"加了又全删"被当成空页面**静默关掉**。
现在看"有没有动过"（撤销栈是否为空）：没动过直接关，动过就弹确认。
探针 `probe-tab-close-guard` 新增第 ⑥ 条专门验这个（11/11 通过）。

### 5. 新建页面时画布滚回左上

滚动位置挂在外层 `.canvas-wrap` 上，换标签只换内容 → 新页面直接继承了上一页的滚动量。
现在切页/新建都滚回 (0,0)。实测：新建前 top=162 → 新建后 top=0。

### 6. 属性卡片的"重进 / 退出"

退场动画重写成你要的两段：**先缩小 + 阴影浮起来 → 再往右滑出去**（340ms）。
Ctrl+Z 把删掉的卡片恢复回来 → 卡片有进场动画；Ctrl+Y 让它再次消失 →
补一条"幽灵行"播同一段退场（点 × 删除那条本来就是自己播，不会重复）。

### 7. 会话页的 × 菜单：点旁边关闭

确认面板现在点页面任何别的地方就收起（点面板自己、点 × 除外）。

### 8. 离开编辑器时工具栏不再"闪一下"

切到会话页时第二条操作栏不再是条件渲染直接卸载，而是**多挂 220ms 从下方滑出**
（期间 `position: fixed` 脱流，不会把会话页顶矮 48px 再弹回来）。
第一条栏换了按钮时也走 200ms 的淡入到位，不是硬替换。

## 5. 「二级菜单飘到上面去了」

真因找到了：定位代码里算了一次"减去面板高度"，CSS 里又 `translateY(-100%)` 减了一次，
于是菜单比按钮高出整整一个面板高度 —— 看着就是"飘到屏幕上方"。

现在只写按钮顶边。**「更多」菜单的底边距离按钮顶边 6px**（实测数字，不是目测）。

另外补了一个坑：竖屏那条工具栏是横滑的，点按钮时浏览器会把按钮滚进视野（scrollIntoView），
这个滚动事件以前会把**刚打开的菜单立刻关掉**；现在打开后 200ms 内的滚动信号不理会。

怎么验：点「更多」/「设备」/「三」，三个菜单都应该紧贴各自按钮，且**不盖住手指**（菜单在按钮上方）。

## 6. 「第一条栏撤销/重做往下掉了」

不是行高问题（我上一版以为是，改成 `line-height: 0` 只解决了一半）——
真因是这两个图标的 SVG 路径画在 22 号 viewBox 的**下半部**，所以整体偏低 8px。
现在路径上移 1.6 单位，五个按钮的图标在同一条水平线上。

怎么验：看第一条栏，撤销/重做和方框数字、新建、三，图标底边应该齐平。

## 7. 「第一条栏最右边更多按钮的二级菜单又飘到上面」

同第 5 条，同一处 bug，一起修了。

## 8. 「点叉叉先退出去、又弹全屏弹窗问保存，交互很奇怪」

改成**贴着那颗 × 弹出的小二级菜单**：

- 干净标签：什么都不问，播 190ms 退场动画直接关；
- 有未保存修改：**原地**在 × 旁边弹出「保存并关闭 / 不保存 / 取消」，点旁边空白＝取消；
- 不再有全屏遮罩 + 居中大卡片（顶部标签条那种没有锚点的地方仍保留居中卡片，那是桌面端的形态）。

怎么验：会话管理页里改点东西 → 回到会话页 → 点那个会话卡片上的 × → 菜单应该出现在 × 左上/左下，
不是屏幕正中央，也不是全屏。

## 9. 「缩略图边框不完整 / 只有文字没有样式」

两个都是真 bug：

- **边框**：缩略图是不透明白底、且自己带 13px 圆角、卡片又是 `overflow: visible`，
  于是它把卡片左右两条边框**盖住了**。现在卡片 `overflow: hidden` 统一裁角，边框整圈都在。
- **没样式**：第一版缩略图是我自己用内联样式画的"迷你盒子"，而这套编辑器的观感八成来自
  预设 / 继承 / 全局规则，不在元素自己的 style 上 → 画出来当然只剩文字。
  现在改成 **走 exporter 生成和「导出 HTML」完全相同的 HTML，塞进 iframe 再整体缩放**，
  保真度和导出一致。

怎么验：会话管理页里，缩略图里应该能看到页面真实的底色、红块、圆角、文字位置。

## 10. 「属性卡片的退出动画没有了，是往右边滑出去」

真因：删除属性行的代码一直在给那一行加 `is-removing` 类，等 340ms 才真删，
但**没有任何 CSS 接这个类** —— 所以表现是"点了删除原地消失"。
现在补上了：**340ms 向右滑出 64px + 淡出**。

怎么验：选中元素 → 属性面板里某条属性右上角 × → 那一行应该往右边滑出去再消失。
