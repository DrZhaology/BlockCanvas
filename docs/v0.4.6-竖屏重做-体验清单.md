## 0. 怎么进竖屏

三种都行，效果完全一样（判据只有一条：窗口宽度 < 900px）：

1. 把窗口拖窄到 900px 以下；
2. 窗口拉高变窄（手机/竖屏平板就是这种）；
3. 浏览器里打开网页版再缩窗口。

判断成功的标志：**顶部整条消失**，屏幕最下面出现一条按钮栏（撤销 / 重做 / 方框数字 / 新建 / 三）。

---

## 1. 「二级菜单的折叠开启关闭线不做了」

已放弃。第二条操作栏那条小横杠现在**只是抓握提示 + 长按手势的起点**，不再假装能"拉开/收起"。

- 怎么验：长按那条横杠（或栏上空白）380ms，再上滑 = 全部按钮铺开；下滑 = 收回一行。

## 2. 「菜单丑死了 / 不给按钮 SVG 下面加文字 / 按钮特别窄」

- 第二条操作栏的每个按钮都是**图标在上 + 文字在下**，最少 52×44，不再是光秃秃的小图标。
- 「更多」和「体检」也补上了文字。
- 二级菜单（更多 / 设备 / 入口）里的每一项都是 **44px 高、13.5px 字**，带图标。

怎么验：看第二条操作栏——每个按钮下面都有 3 个字（更多 / 自适应 / 体检 / 操作 / 预览 / 轮廓 / 导出HTML…）。

## 3. 「Alt 模式的按钮这么小给谁点 + 开了还触发范围选中」

- 按钮从 18px 高的小胶囊 → **26px 高的胶囊 + 完整文字「Alt 模式」**，命中区外扩到 44px。
- 更关键的是逻辑：以前那个开关只改了状态，画布空白处的**框选判定仍旧只看真键盘的 Alt 键**，
  所以你开了 Alt 模式在空白处按住拖，还是被打成框选，把上下平移带坏了。
  现在框选判定改成 `altHeld(e)` —— **开关开着＝一直按着 Alt**，空白处不再起框。

怎么验：点开「Alt 模式」→ 手指在画布空白处按住拖 → 应该是**平移画布**，不出现蓝色选框；
再点一下关掉 → 恢复长按选中。

## 4. 「四个设备按钮全放出来了，应该进二级菜单」

- 「自适应 / 电脑 / 平板 / 手机」四个按钮收成**一个「设备」按钮**（按钮上写当前是哪个），
  点它才弹出二级菜单，菜单紧贴按钮上方。

怎么验：第二条操作栏第 3 个按钮就是「设备」，点开能看到四档，菜单在按钮正上方 6px 处。

## 5. 「二级菜单飘到上面去了」

真因找到了：定位代码里算了一次"减去面板高度"，CSS 里又 `translateY(-100%)` 减了一次，
于是菜单比按钮高出整整一个面板高度 —— 看着就是"飘到屏幕上方"。

现在只写按钮顶边。**「更多」菜单的底边距离按钮顶边 6px**（实测数字，不是目测）。

另外补了一个坑：竖屏那条工具栏是横滑的，点按钮时浏览器会把按钮滚进视野（scrollIntoView），
这个滚动事件以前会把**刚打开的菜单立刻关掉**；现在打开后 200ms 内的滚动信号不理会。

怎么验：点「更多」/「设备」/「三」，三个菜单都应该紧贴各自按钮，且**不盖住手指**（菜单在按钮上方）。

## 6. 「第一条栏撤销/重做往下掉了」

不是行高问题（我上一版以为是，改成 `line-height: 0` 只解决了一半）——
真因是这两个图标的 SVG 路径画在 22 号 viewBox 的**下半部**，所以整体偏低 8px。
现在路径上移 1.6 单位，五个按钮的图标在同一条水平线上。

怎么验：看第一条栏，撤销/重做和方框数字、新建、三，图标底边应该齐平。

## 7. 「第一条栏最右边更多按钮的二级菜单又飘到上面」

同第 5 条，同一处 bug，一起修了。

## 8. 「点叉叉先退出去、又弹全屏弹窗问保存，交互很奇怪」

改成**贴着那颗 × 弹出的小二级菜单**：

- 干净标签：什么都不问，播 190ms 退场动画直接关；
- 有未保存修改：**原地**在 × 旁边弹出「保存并关闭 / 不保存 / 取消」，点旁边空白＝取消；
- 不再有全屏遮罩 + 居中大卡片（顶部标签条那种没有锚点的地方仍保留居中卡片，那是桌面端的形态）。

怎么验：会话管理页里改点东西 → 回到会话页 → 点那个会话卡片上的 × → 菜单应该出现在 × 左上/左下，
不是屏幕正中央，也不是全屏。

## 9. 「缩略图边框不完整 / 只有文字没有样式」

两个都是真 bug：

- **边框**：缩略图是不透明白底、且自己带 13px 圆角、卡片又是 `overflow: visible`，
  于是它把卡片左右两条边框**盖住了**。现在卡片 `overflow: hidden` 统一裁角，边框整圈都在。
- **没样式**：第一版缩略图是我自己用内联样式画的"迷你盒子"，而这套编辑器的观感八成来自
  预设 / 继承 / 全局规则，不在元素自己的 style 上 → 画出来当然只剩文字。
  现在改成 **走 exporter 生成和「导出 HTML」完全相同的 HTML，塞进 iframe 再整体缩放**，
  保真度和导出一致。

怎么验：会话管理页里，缩略图里应该能看到页面真实的底色、红块、圆角、文字位置。

## 10. 「属性卡片的退出动画没有了，是往右边滑出去」

真因：删除属性行的代码一直在给那一行加 `is-removing` 类，等 340ms 才真删，
但**没有任何 CSS 接这个类** —— 所以表现是"点了删除原地消失"。
现在补上了：**340ms 向右滑出 64px + 淡出**。

怎么验：选中元素 → 属性面板里某条属性右上角 × → 那一行应该往右边滑出去再消失。

# 本轮新增的四个东西

## A. 图层搬到了屏幕下方

- 入口：第二条操作栏的「图层」按钮（在「更多」右边）。
- 面板从底部升起，**盖住第二条栏、不盖第一条**（第一条必须一直能点）。
- 左侧窄栏切换「图层 / 属性」；点「属性」＝收起面板 + 打开右侧属性抽屉。
- **图层面板不能直接关**（没有关闭按钮、点旁边不关、下滑也不关），这是你要的防误触；
  离开它只能走「属性」。
- 行内那排小按钮全删了，改**长按一行**弹菜单：删除 / 复制 / 粘贴到内部。
- 「开启拖动」吸顶；拖动模式下长按**不弹菜单**（手势冲突）。
- 只显示最干净的层级（类名徽标、关系选择器徽标都隐藏）。

## B. 竖屏设置（真的生效）

「设置」页导航现在分三块：**通用设置 / 电脑设置 / 竖屏设置**。第三块三条，改完立刻生效：

| 设置项 | 作用 |

| 显示第二条操作栏 | 关掉后画布多 72px 高 |
| 长按判定时长 | 300 / 420 / 600 毫秒，管"在画布上按多久算长按选中" |
| 图层面板高度 | 35% / 42% / 55% |
