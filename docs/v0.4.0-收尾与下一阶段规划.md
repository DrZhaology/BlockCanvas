#### 统一动画约定（以后新增浮层照此办理）

```
<div className={'xxx-mask bc-mask' + (closing ? ' is-closing' : '')} />
<div className={'xxx-pop  bc-pop'  + (closing ? ' is-closing' : '')} />
```

- `lib/useClosing.ts` 把「显示中」拆成 `mounted` / `closing` 两阶段 —— 条件渲染只有进场没有退场，
  元素被瞬间移除，动画根本来不及播。
- `.bc-mask` 淡入淡出、`.bc-pop` 缩放进出；`.is-closing` 触发退场。
- **`.bc-pop` 用 `inset:0 + margin:auto` 居中，不要用 `translate(-50%,-50%)`** ——
  `bcModalIn/bcModalOut` 关键帧里写死了 `transform`，会覆盖居中用的 translate，动画结束元素就跑偏了。
- 折叠区块走 `components/Collapse.tsx`（`grid-template-rows 0fr↔1fr`，进出都有动画）。

#### 设备视口的实现要点

- 机身用 **border 画**（`box-sizing:border-box`，`width = 屏幕宽 + 2×左右边框`），内容框正好是屏幕尺寸。
- 机身画在画布盒子**外面**（负偏移），高度只取设备屏幕高度 —— 手机永远是"一台手机"，
  不会随页面内容被拉成细条（这正是旧版 `is-mobile-frame` 的问题）。
- **`.canvas` 必须 `position: relative`**。之前没写，所有画布内绝对定位元素都锚到了 `.canvas-wrap` 上，
  位置整体错位；加 zoom 后 `.canvas` 有 transform 又"看似正常"，属于典型的时好时坏型 BUG。
- **视口外透明不能用 canvas 的 `mask-image`** —— mask 只覆盖元素自身盒子，会把画在盒子外的机身一起裁掉。
  改用 `.canvas-viewport-outside` 的 `backdrop-filter: opacity(0.32)`：降低的是身后内容本身的透明度，
  页面底色照常透出来，观感才是真的"淡出"。

#### 滚轮调值的实现要点（`lib/wheelAdjust.ts`）

- **React 的 `onWheel` 在 17+ 是被动监听，`preventDefault()` 无效** → 必须
  `el.addEventListener('wheel', h, { passive: false })`。
- 只在 `document.activeElement === 输入框` 时响应，否则在面板上随便滚一下就会误改数值。
- 按累计 `deltaY` 取整除凑一格（`WHEEL_UNIT = 40`），鼠标滚轮与触控板手感才一致。
- 静止 260ms 自动提交；配合 `beginStyleEdit` 会话，一次聚焦 = 一条撤销记录。

## 二、A1 · 导出前体检向导

**入口**：工具栏 ⚠ 按钮（角标显示待处理条数）；导出 HTML / 预览前若存在「严重」问题会**自动拦截**。

**体检项**（按严重度排序，每条都带一键修复）：

| 级别 | 检查项 | 一键修复 |
|---|---|---|
| ⛔ 严重 | 写了 `:hover` / `:active` 却没有类名 → 导出后效果**全部丢失** | 按标签自动起类名（`.btn` / `.card` …） |
| ⛔ 严重 | ID 重复 → 浏览器只认第一个 | 保留第一个，其余自动加序号 |
| ⛔ 严重 | 类名不合法（中文 / 空格 / 数字开头）→ CSS 选不中 | 引导去类名总览改名 |
| ⚠️ 提醒 | 元素没有类名 / ID → 样式只能写行内，以后改一处要改 N 处 | 全部自动起名 |
| ⚠️ 提醒 | 同名类名样式不统一 → 导出后互相覆盖，谁生效看运气 | 以第一个为准统一 |
| ⚠️ 提醒 | 链接没有 href → 点击没反应 | 定位到元素 |
| 💡 提示 | 图片缺 alt | 定位到元素 |
| 💡 提示 | 固定宽度 > 360px，窄屏可能横向溢出 | 定位到元素；配合「整页自动适配」 |

**交互**：左侧问题清单 + 右侧当前项详情（讲因果不讲术语）+ 底部「上一项 / 下一项 / 一键修复全部 / 去处理」。
支持 ← → 键切换、Esc 关闭。「一键修复全部」在撤销栈里算**一步**。

相关文件：`src/renderer/lib/healthCheck.ts`、`src/renderer/components/HealthWizard.tsx`

## 三、A2 · 设计变量 / Token 体系

**解决的问题**：改一个主色要在十个元素里改十次。

**做法**：
- 项目级定义 `--bc-primary` / `--bc-radius-md` / `--bc-space-md` …（新项目预置 15 个常用变量）
- 元素样式里写 `var(--bc-primary)`，改一处全站跟着变
- 编辑器里把这些变量注入 `document.documentElement`，**画布用原生 `var()` 解析 → 所见即所得**，不需要额外的替换逻辑
- 导出时 `:root{...}` 写在 `<style>` **最前面**，脱离本软件同样生效

**怎么用**：
1. 右侧面板新增「**变量**」页签：按颜色 / 圆角 / 间距 / 文字 / 阴影分组，显示每个变量被引用了多少处
2. 任意颜色输入框 → 打开调色盘 → 顶部「设计变量」区点一下，即写入 `var()` 引用而不是写死颜色
3. 改名会**连带把所有已引用的 `var(--bc-old)` 换成新的**，引用不会断（算一步撤销）

**注意**：变量名只能用小写字母开头，且只包含小写字母 / 数字 / 连字符。

相关文件：`src/renderer/lib/designTokens.ts`、`src/renderer/components/TokenPanel.tsx`

## 四、建议你这样验收（约 15 分钟）

1. **版本号**：`package.json` 显示 `0.4.0`。
2. **手机外框**：切到手机宽度 → 画布**不应**出现手机外框；点工具栏「🖥 视口」→ 出现屏幕框，视口外变暗。
3. **断点切换**：在工具栏切「自适应 / 桌面 / 平板 / 手机」→ 画布宽度平滑过渡；拖动画布边缘调宽时应当 1:1 跟手（无延迟）。
4. **技巧入口**：点工具栏「💡 技巧」→ 弹小卡片可换一条 / 不再提示；画布左上角已无提示条。
5. **长按调值**：任意数值输入框按住约 0.35 秒 → 指针消失，左右移动改数值，松开后指针回到原位；单击仍是正常输入。
6. **内外边距单位**：「内边距」右上角应能切换 px / % / rem 等单位。
7. **调色盘**：任意颜色 → 全屏黑色遮罩 + 居中卡片；面板里没有「设为透明」按钮；顶部有「设计变量」区（新项目应有 6 个颜色变量）。
8. **变量联动**：给某元素背景色选 `var(--bc-primary)` → 到「变量」页签把 primary 改成别的颜色 → 画布上该元素立刻变色。
9. **边框 / 阴影**：加「边框」→ 四边粗细、线型、颜色可分别调，有实时预览；加「盒子阴影」→ 选中该元素时阴影**仍然可见**。
10. **导出拦截**：造一个「写了 hover 但没类名」的元素 → 点「导出 HTML」→ 应**先弹体检向导**并高亮那条严重问题；点「自动起类名」后消失。
11. **状态记忆**：勾上四值输入的「四边同步」→ 重启软件后仍勾着。
12. **深色模式**：切换深浅色，确认过渡动画正常（说明去掉 `!important` 无副作用）。
13. **工具栏两行**：第一行是操作按钮，第二行左侧是三断点 + 画布宽度、右侧是小技巧文字；
    小技巧每 15 秒自动换一条，点文字立刻换，点 × 收起（设置里可恢复）。
14. **滚轮调值**：点一下任意数值框 → 滚动滚轮数值跟着变，按住 Shift 一次跳 10；
    停手约 0.26 秒自动提交；失焦后再滚不会误改。
15. **真机边框**：开「🖥 视口」后切三种设备 —— 电脑是细边框 + 下巴、平板是厚边框 + 摄像头、
    手机是大圆角 + 灵动岛 + Home 条；**机身高度不随页面内容变长**；屏幕之外的内容明显变淡。
16. **动画**：体检向导关闭时有淡出；预制渐变展开/收起都有过渡；关系选择器弹层居中且进出都有动画。
17. **滑块**：属性面板里的滑块（透明度、过渡、滤镜、色标位置、边框粗细）应撑满剩余宽度，不再是一小截。

## 八、v0.4.3 迭代补记（2026-09-18）

> 本节修订上文与本轮直接冲突的三处设计决策，完整记录见 `docs/开发历程.md`。

1. **工具栏「两行式」→「单行式」**：上文第 4 批的"两行方案"被取代。
   现在只有一条工具栏（44px）：左固定（编辑操作+预览+导出）｜中滚动区（可管理按钮 + 插件命令，
   最宽 1/2、细滚动条、scroll-snap 吸附按钮）｜右系统（设备三段切换 + 视口开关一体、缩放、
   体检 ⚠、⋯ 更多、设置）。缩放「归位」按钮只在 zoom ≠ 100% 时出现。
2. **小技巧常驻位置**：从工具栏移到**项目标签栏右端**（只留 × 关闭、双击换条）；
   标签宽度自适应（少→平分变宽、多→压缩+5px 细滚动条），「＋新建」移出滚动区。
3. **设备视口外壳 v2**：上文"真实设备边框"升级为"真机感"——
   电脑（Mac 刘海 + 下巴 + 支架底座）、手机（屏幕内灵动岛 + Home 条 + 侧键）、
   平板（摄像头 + Home 条 + 侧键），机身金属渐变 + 屏幕暗角高光。
   实现要点不变：border 画机身、画布外负偏移、`.canvas` 保持 `position: relative`、
   视口外用 `backdrop-filter: opacity()`。
4. **设置页工具栏编辑器重写**：真实样式预览（chips 可拖拽排序）+ 每项独立开关，
   数据仍走 `toolbarStore`；可管理按钮 id 收敛为 `toolbarStore.SCROLL_BUILTIN_IDS`。
5. **两个逻辑 BUG 修复**：行内元素选中框（outline 按行盒拆多框 → Canvas 层合并外框）、
   hover/active 无过渡（`parseDuration` 兜底 0.3s 造成"已开启"假象 → 套用预制自动补
   `transition: all .3s ease` + 滑块显示诚实化）。
